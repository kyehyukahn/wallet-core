# 608. React Native 연동 빌드 가이드

wallet-core를 React Native 앱에서 사용하기 위한 빌드 및 통합 가이드.

> **현황**: wallet-core에는 공식 React Native 바인딩이 없다. 이 문서는 기존 iOS/Android 바인딩을 활용하여 RN에서 사용하는 방법을 설명한다.

## 아키텍처 개요

```
React Native (JS/TS)
    │
    ├─── Turbo Module (New Architecture, 권장)
    │    또는 Native Module (Old Architecture)
    │
    ├───────────────────┬───────────────────┐
    │   iOS             │   Android         │
    │   Swift 래퍼      │   Kotlin 래퍼     │
    │   (TW* C 함수)    │   (JNI → TW*)     │
    └───────────────────┴───────────────────┘
            │                    │
            └─── C Interface ────┘
                 (include/TrustWalletCore/TW*.h)
                      │
              ┌───────┴───────┐
              │  C++ Core     │
              │  Rust Core    │
              │  TrezorCrypto │
              └───────────────┘
```

React Native는 플랫폼별로 다른 경로로 wallet-core에 접근한다:
- **iOS**: Swift/ObjC 바인딩 → TW* C 함수 직접 호출
- **Android**: Kotlin/Java 바인딩 → JNI → TW* C 함수 호출

---

## 방법 A: 기존 배포 바이너리 사용 (빌드 불필요)

가장 간단한 방법. 이미 빌드된 라이브러리를 가져다 쓴다.

### iOS 측 (CocoaPods)

RN 프로젝트의 `ios/Podfile`에 추가:

```ruby
# ios/Podfile
target 'YourApp' do
  # ... 기존 RN pods ...

  pod 'TrustWalletCore'
  # 또는 특정 버전
  # pod 'TrustWalletCore', '~> 4.1.0'
end
```

```bash
cd ios && pod install
```

### Android 측 (Gradle)

프로젝트 `android/build.gradle`에 GitHub Packages 저장소 추가:

```groovy
// android/build.gradle (root)
allprojects {
    repositories {
        // ... 기존 ...
        maven {
            url = uri("https://maven.pkg.github.com/trustwallet/wallet-core")
            credentials {
                username = project.findProperty("gpr.user") ?: System.getenv("GITHUB_USER")
                password = project.findProperty("gpr.key") ?: System.getenv("GITHUB_TOKEN")
            }
        }
    }
}
```

앱 모듈 `android/app/build.gradle`에 의존성 추가:

```groovy
// android/app/build.gradle
dependencies {
    implementation "com.trustwallet:wallet-core-kotlin:$walletCoreVersion"
}
```

> GitHub Personal Access Token (read:packages 권한)이 필요하다.
> `local.properties`에 `gpr.user`와 `gpr.key`를 설정하거나 환경변수 사용.

## 방법 B: 소스에서 직접 빌드

R_WALLET 프로젝트처럼 wallet-core를 커스텀하거나 최신 코드를 사용해야 할 때.

### 사전 조건

```bash
cd wallet-core

# 전체 의존성 설치 (최초 1회, 15~30분 소요)
./bootstrap.sh ios android
```

이 명령이 수행하는 것:
1. 시스템 의존성 (brew: boost, ninja, xcodegen, cmake 등)
2. C++ 라이브러리 (protobuf 3.20.3, gtest, check)
3. Rust 툴체인 (nightly-2025-12-11 + 크로스 컴파일 타겟)
4. iOS Rust 타겟 (aarch64-apple-ios, simulator 등)
5. Android NDK + Rust 타겟 (arm64, armv7, x86, x86_64)
6. 코드 생성 (protobuf, 바인딩, Xcode 프로젝트)

### iOS 빌드

```bash
# 코드 생성 (proto 변경 시 필수)
tools/generate-files ios

# 방법 1: 로컬 CocoaPods로 사용
# RN 프로젝트의 Podfile에서 로컬 경로 지정:
#   pod 'TrustWalletCore', :path => '../wallet-core'

# 방법 2: xcframework 빌드
tools/ios-build
# 결과: build/ios-frameworks/WalletCoreCommon.xcframework
```

### Android 빌드

```bash
# 코드 생성
tools/generate-files android

# Kotlin/KMP 라이브러리 빌드
tools/kotlin-build

# 또는 AAR 릴리즈 빌드
tools/android-build
# 결과: build/wallet-core.aar
```

로컬 AAR을 RN Android 프로젝트에서 사용:

```groovy
// android/app/build.gradle
dependencies {
    implementation files('../../wallet-core/build/wallet-core.aar')
}
```

## Native Module 작성 가이드

### 프로젝트 구조 (Turbo Module 기준)

```
your-rn-app/
├── src/
│   └── wallet/
│       └── index.ts              ← JS API
├── ios/
│   └── WalletCoreModule.swift    ← iOS 네이티브 모듈
├── android/
│   └── app/src/main/java/.../
│       └── WalletCoreModule.kt   ← Android 네이티브 모듈
└── package.json
```

### iOS Native Module 예시 (Swift)

wallet-core의 Swift 바인딩은 이미 사용하기 편한 클래스로 래핑되어 있다:

```swift
// ios/WalletCoreModule.swift
import Foundation
import WalletCore

@objc(WalletCoreModule)
class WalletCoreModule: NSObject {

  // 니모닉 생성
  @objc func createWallet(
    _ strength: Int,
    resolve: @escaping RCTPromiseResolveBlock,
    reject: @escaping RCTPromiseRejectBlock
  ) {
    guard let wallet = HDWallet(strength: Int32(strength), passphrase: "") else {
      reject("ERROR", "Failed to create wallet", nil)
      return
    }
    resolve([
      "mnemonic": wallet.mnemonic,
    ])
  }

  // 니모닉으로 복원
  @objc func importWallet(
    _ mnemonic: String,
    resolve: @escaping RCTPromiseResolveBlock,
    reject: @escaping RCTPromiseRejectBlock
  ) {
    guard let wallet = HDWallet(mnemonic: mnemonic, passphrase: "") else {
      reject("ERROR", "Invalid mnemonic", nil)
      return
    }
    resolve([
      "mnemonic": wallet.mnemonic,
    ])
  }

  // 주소 파생
  @objc func getAddress(
    _ mnemonic: String,
    coinType: Int,
    resolve: @escaping RCTPromiseResolveBlock,
    reject: @escaping RCTPromiseRejectBlock
  ) {
    guard let wallet = HDWallet(mnemonic: mnemonic, passphrase: "") else {
      reject("ERROR", "Invalid mnemonic", nil)
      return
    }
    guard let coin = CoinType(rawValue: UInt32(coinType)) else {
      reject("ERROR", "Invalid coin type", nil)
      return
    }
    let address = wallet.getAddressForCoin(coin: coin)
    resolve(address)
  }

  // 주소 유효성 검증
  @objc func validateAddress(
    _ address: String,
    coinType: Int,
    resolve: @escaping RCTPromiseResolveBlock,
    reject: @escaping RCTPromiseRejectBlock
  ) {
    guard let coin = CoinType(rawValue: UInt32(coinType)) else {
      reject("ERROR", "Invalid coin type", nil)
      return
    }
    let isValid = AnyAddress.isValid(string: address, coin: coin)
    resolve(isValid)
  }

  // 트랜잭션 서명 (Protobuf 바이트 기반)
  @objc func sign(
    _ inputData: String,  // base64 encoded SigningInput protobuf
    coinType: Int,
    resolve: @escaping RCTPromiseResolveBlock,
    reject: @escaping RCTPromiseRejectBlock
  ) {
    guard let coin = CoinType(rawValue: UInt32(coinType)) else {
      reject("ERROR", "Invalid coin type", nil)
      return
    }
    guard let input = Data(base64Encoded: inputData) else {
      reject("ERROR", "Invalid input data", nil)
      return
    }
    let output = AnySigner.sign(input: input, coin: coin)
    resolve(output.base64EncodedString())
  }
}
```

### Android Native Module 예시 (Kotlin)

```kotlin
// android/app/src/main/java/.../WalletCoreModule.kt
package com.yourapp

import com.facebook.react.bridge.*
import wallet.core.jni.HDWallet
import wallet.core.jni.AnyAddress
import wallet.core.jni.AnySigner
import wallet.core.jni.CoinType
import android.util.Base64

class WalletCoreModule(reactContext: ReactApplicationContext)
  : ReactContextBaseJavaModule(reactContext) {

  companion object {
    init {
      System.loadLibrary("TrustWalletCore")
    }
  }

  override fun getName() = "WalletCoreModule"

  // 니모닉 생성
  @ReactMethod
  fun createWallet(strength: Int, promise: Promise) {
    try {
      val wallet = HDWallet(strength, "")
      val result = Arguments.createMap().apply {
        putString("mnemonic", wallet.mnemonic())
      }
      promise.resolve(result)
    } catch (e: Exception) {
      promise.reject("ERROR", e.message)
    }
  }

  // 니모닉으로 복원
  @ReactMethod
  fun importWallet(mnemonic: String, promise: Promise) {
    try {
      val wallet = HDWallet(mnemonic, "")
      val result = Arguments.createMap().apply {
        putString("mnemonic", wallet.mnemonic())
      }
      promise.resolve(result)
    } catch (e: Exception) {
      promise.reject("ERROR", e.message)
    }
  }

  // 주소 파생
  @ReactMethod
  fun getAddress(mnemonic: String, coinType: Int, promise: Promise) {
    try {
      val wallet = HDWallet(mnemonic, "")
      val coin = CoinType.createFromValue(coinType)
      val address = wallet.getAddressForCoin(coin)
      promise.resolve(address)
    } catch (e: Exception) {
      promise.reject("ERROR", e.message)
    }
  }

  // 주소 유효성 검증
  @ReactMethod
  fun validateAddress(address: String, coinType: Int, promise: Promise) {
    try {
      val coin = CoinType.createFromValue(coinType)
      val isValid = AnyAddress.isValid(address, coin)
      promise.resolve(isValid)
    } catch (e: Exception) {
      promise.reject("ERROR", e.message)
    }
  }

  // 트랜잭션 서명
  @ReactMethod
  fun sign(inputBase64: String, coinType: Int, promise: Promise) {
    try {
      val coin = CoinType.createFromValue(coinType)
      val input = Base64.decode(inputBase64, Base64.DEFAULT)
      val output = AnySigner.sign(input, coin)
      promise.resolve(Base64.encodeToString(output, Base64.NO_WRAP))
    } catch (e: Exception) {
      promise.reject("ERROR", e.message)
    }
  }
}
```

### JS/TS 인터페이스

```typescript
// src/wallet/index.ts
import { NativeModules, Platform } from 'react-native';

const { WalletCoreModule } = NativeModules;

// CoinType 상수 (registry.json 기반)
export enum CoinType {
  Bitcoin = 0,
  Ethereum = 60,
  BinanceSmartChain = 20000714,
  Solana = 501,
  Cosmos = 118,
  // ... 130+ 체인
}

export interface WalletInfo {
  mnemonic: string;
}

// 지갑 생성 (128=12단어, 256=24단어)
export function createWallet(strength: number = 128): Promise<WalletInfo> {
  return WalletCoreModule.createWallet(strength);
}

// 니모닉으로 복원
export function importWallet(mnemonic: string): Promise<WalletInfo> {
  return WalletCoreModule.importWallet(mnemonic);
}

// 코인별 주소 파생
export function getAddress(mnemonic: string, coinType: CoinType): Promise<string> {
  return WalletCoreModule.getAddress(mnemonic, coinType);
}

// 주소 유효성 검증
export function validateAddress(address: string, coinType: CoinType): Promise<boolean> {
  return WalletCoreModule.validateAddress(address, coinType);
}

// 트랜잭션 서명 (base64 encoded protobuf)
export function sign(inputBase64: string, coinType: CoinType): Promise<string> {
  return WalletCoreModule.sign(inputBase64, coinType);
}
```

## 핵심 C API 매핑

React Native에서 노출할 주요 wallet-core API:

| C API (TW*.h) | 기능 | RN 메서드 예시 |
|---------------|------|---------------|
| `TWHDWalletCreate` | 니모닉 생성 | `createWallet(strength)` |
| `TWHDWalletCreateWithMnemonic` | 니모닉 복원 | `importWallet(mnemonic)` |
| `TWHDWalletGetAddressForCoin` | 주소 파생 | `getAddress(mnemonic, coin)` |
| `TWHDWalletGetKeyForCoin` | 프라이빗 키 파생 | `getPrivateKey(mnemonic, coin)` |
| `TWAnyAddressIsValid` | 주소 검증 | `validateAddress(address, coin)` |
| `TWAnySignerSign` | 트랜잭션 서명 | `sign(inputProto, coin)` |
| `TWAnySignerPlan` | UTXO 수수료 계획 | `plan(inputProto, coin)` |
| `TWMnemonicIsValid` | 니모닉 검증 | `validateMnemonic(mnemonic)` |
| `TWPrivateKeySign` | 메시지 서명 | `signMessage(key, message)` |
| `TWEthereumAbiEncode` | ABI 인코딩 | `encodeABI(function, params)` |

### 데이터 전달 규칙

| 방향 | 형식 |
|------|------|
| JS → Native (바이트 데이터) | Base64 인코딩 문자열 |
| Native → JS (바이트 데이터) | Base64 인코딩 문자열 |
| JS → Native (문자열) | UTF-8 문자열 그대로 |
| JS → Native (Protobuf) | Base64로 직렬화된 protobuf 바이트 |
| Native → JS (Protobuf) | Base64로 직렬화된 protobuf 바이트 |

> **Protobuf 직렬화**: JS 측에서 `protobufjs`나 `@bufbuild/protobuf`로 SigningInput을 만들어
> Base64로 인코딩 후 네이티브로 전달. 네이티브가 `TWAnySignerSign`을 호출하고
> SigningOutput을 Base64로 돌려준다.

## 플랫폼별 빌드 요약

### 빌드가 필요한 것

| 빌드 대상 | 명령어 | 결과물 |
|-----------|--------|--------|
| iOS (CocoaPods) | `bootstrap.sh ios` + `generate-files ios` | Podspec으로 자동 빌드 |
| iOS (xcframework) | `tools/ios-build` | `WalletCoreCommon.xcframework` |
| Android (AAR) | `bootstrap.sh android` + `tools/android-build` | `build/wallet-core.aar` |
| Android (Kotlin/KMP) | `tools/kotlin-build` | Gradle 아티팩트 |

### RN 프로젝트 설정

```bash
# RN 프로젝트에서
cd your-rn-app

# iOS 의존성
cd ios && pod install && cd ..

# Android는 Gradle sync에서 자동 처리
cd android && ./gradlew assembleDebug && cd ..
```

## 성능 고려사항

| 방식 | Bridge 오버헤드 | 적합한 용도 |
|------|----------------|------------|
| Native Module (Bridge) | 직렬화/역직렬화 비용 | 대부분의 지갑 기능 |
| Turbo Module (JSI) | 최소 | 빈번한 호출, 배치 작업 |
| WASM (npm) | WASM 런타임 오버헤드 | 프로토타이핑 |

**지갑 앱의 경우**, 대부분의 작업(지갑 생성, 주소 파생, 트랜잭션 서명)은 빈번하지 않으므로 **Native Module (Bridge) 방식으로 충분**하다. 초당 수백 건의 호출이 필요한 경우에만 JSI/Turbo Module을 고려.

## 보안 주의사항

1. **니모닉/프라이빗 키**: JS Bridge를 통해 전달 시 메모리에 남을 수 있음. 민감한 키 작업은 가능한 네이티브 측에서만 처리
2. **Hermes**: 디버그 빌드에서 JS 코드가 평문으로 노출될 수 있음. 릴리즈 빌드에서는 Hermes 바이트코드 사용
3. **키체인/키스토어**: 생성된 키는 iOS Keychain / Android Keystore에 저장 권장
4. **Protobuf 전달**: Base64 인코딩은 암호화가 아님. 트랜잭션 서명 자체는 네이티브에서 수행되므로 프라이빗 키가 JS로 올라갈 필요 없음
