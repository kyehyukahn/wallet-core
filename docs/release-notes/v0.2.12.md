# v0.2.12 — Android library publication wiring + versionName variable fix

Android-only patch over v0.2.11. iOS artifacts byte-identical.

## What was broken

Two cooperating bugs in `npm-package/android/build.gradle`:

### 1. `versionName package_json['version']` referenced an undefined variable

When v0.2.10 replaced the `groovy.json.JsonSlurper` parse with a Groovy string literal (`def package_version = '0.2.10'`), the `versionName` line was missed and kept referencing the now-non-existent `package_json` map. Caused a NameError that Gradle reported as a child-of-configure failure.

### 2. `publishing.singleVariant("release") { }` alone wasn't enough

`expo-module-gradle-plugin` references `components.release` at configure time. AGP's `singleVariant` declaration creates the SoftwareComponent late in evaluation (after `afterEvaluate`), so the plugin's hook fires before the component exists and produces:

```
A problem occurred configuring project ':kyehyukahn-wallet-core'.
> SoftwareComponent with name 'release' not found.
```

## Fix

Three coordinated changes:

1. `versionName package_json['version']` → `versionName package_version` (use the existing Groovy literal).
2. Apply `maven-publish` plugin explicitly at the top of the file. expo-module-gradle-plugin assumes it's there; declaring it ourselves avoids a transitive-application gap.
3. Add an `afterEvaluate { publishing { publications { release(MavenPublication) { from components.release; ... } } } }` block that materialises the publication AFTER the SoftwareComponent has been registered. Works in tandem with `android.publishing.singleVariant("release") { withSourcesJar() }` from v0.2.11.

```gradle
apply plugin: 'com.android.library'
apply plugin: 'kotlin-android'
apply plugin: 'maven-publish'
apply plugin: 'expo-module-gradle-plugin'

def package_version = '0.2.12'

android {
    namespace 'expo.modules.walletcore'
    ...
    defaultConfig {
        versionCode 1
        versionName package_version
    }
    publishing {
        singleVariant("release") {
            withSourcesJar()
        }
    }
}

afterEvaluate {
    publishing {
        publications {
            release(MavenPublication) {
                from components.release
                groupId = group
                artifactId = 'wallet-core'
                version = package_version
            }
        }
    }
}
```
