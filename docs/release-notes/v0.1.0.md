# v0.1.0 — first cirqle-facing release

First release of the **kyehyukahn/wallet-core** fork, built and tested for
consumption by the cirqle React Native app.

## What's in this fork (vs. trustwallet/wallet-core upstream)

- **Bitcoin SPV stack** under `rust/frameworks/tw_spv` and
  `rust/frameworks/tw_wallet_manager` — async SPV client with chain
  implementations for Bitcoin / Bitcoin Cash / Litecoin / Dogecoin, plus
  a tokio-based runtime.
- **C FFI surface** for the above:
  `include/TrustWalletCore/TWBitcoinSpvSync.h`,
  `include/TrustWalletCore/TWBitcoinWalletManager.h`, with Rust bindings
  under `rust/wallet_core_rs/src/ffi/spv` and `.../wallet_manager`.
- **Build environment cleanup** so the fork compiles on a current Apple
  Silicon Mac toolchain — see commit
  `build(ios): suppress implicit int-to-float warning in WalletCoreCommon target`.
- **Documentation** (`docs/200`–`docs/900`) covering architecture,
  per-platform build guides, troubleshooting, and license compliance.

NDK 28.0.12674087, cmake 3.18.1, Rust nightly-2025-12-11.

## How to consume

```bash
# project .npmrc
@kyehyukahn:registry=https://npm.pkg.github.com

# install
pnpm add @kyehyukahn/wallet-core@^0.1.0
```

The npm package wrapper downloads and verifies the artifacts attached
to this Release, then exposes path resolvers
(`iosCommonXcframework()`, `iosRsXcframework()`, `androidAar()`). See
the package README for details.

## Known limitations

- **wasm build is currently broken** on this branch: `tw_spv` uses tokio,
  whose dependency `mio` does not support `wasm32-unknown-emscripten`.
  This does not affect iOS/Android. See
  `docs/607.build-troubleshooting.md` (WASM section) for the diagnosis
  and the planned fix path (Cargo feature gate or async runtime swap).
- iOS device-slice archival requires the matching iOS platform
  component to be installed in Xcode (Settings → Components). The SDK
  alone is not sufficient on Xcode 16+; see `docs/607` (iOS section).

## Reproducing this release locally

```bash
git checkout v0.1.0
./bootstrap.sh                            # install C++/proto deps
tools/install-rust-dependencies
tools/install-android-dependencies        # NDK + cmake;3.18.1
tools/generate-files ios                  # produces swift/WalletCoreRs.xcframework
tools/ios-build                           # produces build/ios-frameworks/WalletCoreCommon.xcframework
tools/generate-files android              # produces rust android libs
tools/android-build                       # produces build/wallet-core.aar
tools/release-pack 0.1.0                  # produces build/release-v0.1.0/
```
