# v0.2.7 — fix WalletCoreModule.deriveAddress wrong wallet-core API

iOS + Android patch over v0.2.6. Bug in **our** Expo Module bridge code, not in the upstream wallet-core API. xcframework / AAR / proto.jar binaries and the swift-sources.tar.gz are byte-identical to v0.2.6 (the change is only in the two `WalletCoreModule.{swift,kt}` files shipped inside the package).

## What was broken

After v0.2.6 fixed B7 (xcframework relocation), xcodebuild compiled through every wallet-core Swift wrapper cleanly. **3 remaining failures** were all in our own `WalletCoreModule.swift` / `WalletCoreModule.kt`:

```
.../npm-package/ios/WalletCoreModule.swift:39:46:
  error: type 'CoinTypeConfiguration' has no member 'getPublicKeyType'
```

The `deriveAddress` AsyncFunction was written as:

```swift
let privateKey = wallet.getKey(coin: coinType, derivationPath: path)
let pubKeyType = CoinTypeConfiguration.getPublicKeyType(coin: coinType)   // ← does not exist
let publicKey = privateKey.getPublicKeyByType(pubkeyType: pubKeyType)
return AnyAddress(publicKey: publicKey, coin: coinType).description
```

`CoinTypeConfiguration` only exposes `getSymbol / getDecimals / getTransactionURL / getAccountURL / getID / getName`. There is no `getPublicKeyType`. (This was a guess in the original v0.2.0 scaffold that survived because B2~B7 prevented xcodebuild from ever reaching this code.)

## Fix

`PrivateKey.getPublicKey(coinType:)` (Swift) / `PrivateKey.getPublicKey(coinType)` (Kotlin) takes a `CoinType` directly and picks the right curve internally — exactly the lookup we were trying to do manually. Both `WalletCoreModule.swift` and `WalletCoreModule.kt` now use it:

```swift
// iOS
let privateKey = wallet.getKey(coin: coinType, derivationPath: path)
let publicKey = privateKey.getPublicKey(coinType: coinType)
return AnyAddress(publicKey: publicKey, coin: coinType).description
```

```kotlin
// Android
val privateKey = wallet.getKey(coinType, path)
val publicKey = privateKey.getPublicKey(coinType)
AnyAddress(publicKey, coinType).description()
```

The unused `import wallet.core.jni.CoinTypeConfiguration` was also removed from the Kotlin file.
