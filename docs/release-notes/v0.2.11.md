# v0.2.11 — declare singleVariant('release') for the Android library

Android-only patch over v0.2.10. iOS artifacts byte-identical.

## What was broken (B9, surfaced on first configure pass with v0.2.10)

```
A problem occurred configuring project ':kyehyukahn-wallet-core'.
> SoftwareComponent with name 'release' not found.
```

`expo-module-gradle-plugin` (transitively, AGP's `LibraryExtension`) tries to resolve a `release` SoftwareComponent at configure time so it can be referenced for Maven publication metadata. With modern AGP, library modules must explicitly declare which variant they publish via the `publishing { singleVariant(...) { } }` block; the variant isn't inferred automatically anymore.

v0.2.10 fixed B8 (versionName) but didn't add the publishing block, so configure failed at the next stage.

## Fix

```gradle
android {
    ...
    publishing {
        singleVariant("release") {
            withSourcesJar()
        }
    }
}
```

`withSourcesJar()` ensures the source JAR is also produced — keeps `apply plugin: 'maven-publish'` (transitively used by the Expo Module plugin) happy.
