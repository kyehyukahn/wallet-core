# 602. Rust 빌드

wallet-core의 Rust 크레이트를 개별적으로 빌드하고 테스트하는 방법.

## 사전 조건

- Rust nightly-2025-12-11 설치 (`tools/install-rust-dependencies dev`)
- cbindgen 설치됨

## Rust 워크스페이스 구조

```
rust/
├── Cargo.toml                  ← 워크스페이스 루트
├── chains/
│   ├── tw_bitcoin/             ← Bitcoin 구현
│   ├── tw_ethereum/            ← Ethereum 구현
│   ├── tw_solana/              ← Solana 구현
│   ├── tw_cosmos/              ← Cosmos 구현
│   └── ...                     ← 기타 체인들
├── frameworks/
│   ├── tw_utxo/                ← UTXO 공통 프레임워크
│   ├── tw_spv/                 ← Bitcoin SPV/P2P 네트워킹 (신규)
│   ├── tw_wallet_manager/      ← Bitcoin 월렛 상태 관리 (신규)
│   ├── tw_substrate/           ← Substrate 프레임워크
│   └── tw_ton_sdk/             ← TON SDK
├── tw_any_coin/                ← Rust 측 디스패처 (C++ AnySigner 미러)
│   └── src/ffi/                ← C ABI 노출 지점
├── tw_coin_registry/           ← 코인 타입 레지스트리
├── tw_keypair/                 ← 키페어 유틸
├── tw_hash/                    ← 해시 유틸
├── tw_encoding/                ← 인코딩 유틸
├── tw_tests/
│   └── tests/chains/           ← 체인별 통합 테스트
├── wallet_core_bin/            ← CLI 바이너리 (개발용)
└── wallet-core-rs/             ← C FFI 라이브러리 크레이트
```

## Rust 라이브러리 빌드 (C FFI용)

네이티브 `libwallet_core_rs.a` 빌드:

```bash
cd rust
cargo build --release --lib
```

빌드 결과: `rust/target/release/libwallet_core_rs.a`

> 이 파일은 C++ 빌드에서 링크된다. `tools/rust-bindgen native`가 이 과정을 자동화한다.

## 크로스 컴파일 타겟별 빌드

`tools/rust-bindgen`이 자동으로 수행하지만, 수동으로 하려면:

### Android 타겟

```bash
cd rust

# NDK 경로 설정 필요
export AR="$NDK_BIN_PATH/llvm-ar"
export CC_aarch64_linux_android="$NDK_BIN_PATH/aarch64-linux-android21-clang"
export CC_x86_64_linux_android="$NDK_BIN_PATH/x86_64-linux-android21-clang"
export CC_i686_linux_android="$NDK_BIN_PATH/i686-linux-android21-clang"
export CC_armv7_linux_androideabi="$NDK_BIN_PATH/armv7a-linux-androideabi21-clang"

cargo build -Z build-std=std,panic_abort \
    --target aarch64-linux-android \
    --target armv7-linux-androideabi \
    --target x86_64-linux-android \
    --target i686-linux-android \
    --release --lib
```

### iOS 타겟

```bash
cd rust

cargo build -Z build-std=std,panic_abort \
    --target aarch64-apple-ios \
    --target aarch64-apple-ios-sim \
    --target x86_64-apple-ios \
    --target aarch64-apple-darwin \
    --target x86_64-apple-darwin \
    --release --lib

# Universal binary 생성
lipo target/x86_64-apple-ios/release/libwallet_core_rs.a \
     target/aarch64-apple-ios-sim/release/libwallet_core_rs.a \
     -create -output target/libwallet_core_rs.a
```

### WASM 타겟

```bash
source emsdk/emsdk_env.sh
cd rust

cargo build -Z build-std=std,panic_abort \
    --target wasm32-unknown-emscripten \
    --release --lib
```

## SPV / Wallet Manager 빌드

Phase 1~4에서 추가된 `tw_spv`와 `tw_wallet_manager` crate 빌드 및 테스트 방법.

### 기본 테스트

```bash
cd rust

# SPV 테스트 (블룸필터, 머클블록, 메시지, 피어, 동기화)
cargo test -p tw_spv

# SPV + TokioRuntime 포함 테스트 (실제 DNS 해석 등)
cargo test -p tw_spv --features tokio-runtime

# 월렛 매니저 테스트 (주소 파생, UTXO, 트랜잭션, persistence, recovery)
cargo test -p tw_wallet_manager

# 통합 테스트만
cargo test -p tw_spv --test integration_test
cargo test -p tw_wallet_manager --test integration_test
```

### FFI 빌드

SPV/Wallet 기능은 `wallet-core-rs`의 `spv` feature로 제공된다:

```bash
cd rust

# spv feature 포함 빌드 (기본적으로 활성화됨)
cargo build -p wallet-core-rs

# spv feature 없이 빌드 (기존 기능만)
cargo build -p wallet-core-rs --no-default-features --features "any-coin,bitcoin,ethereum,evm,keypair,solana,ton,utils"
```

### C 헤더

SPV/Wallet FFI 헤더는 아래 경로에 있으며, `tools/generate-files`로 Swift/Kotlin 바인딩을 생성할 수 있다:

- `include/TrustWalletCore/TWBitcoinWalletManager.h` — 월렛 관리 (12 functions)
- `include/TrustWalletCore/TWBitcoinSpvSync.h` — SPV 동기화 (10 functions)

```bash
# 바인딩 생성 (기존 generate-files와 동일한 파이프라인)
tools/generate-files native     # C++ wrapper
tools/generate-files ios        # Swift
tools/generate-files android    # Kotlin
```

## 주의사항

1. **nightly 필수**: `-Z build-std` 플래그 때문에 nightly 툴체인이 필수
2. **RUSTFLAGS**: 크로스 컴파일 시 `-Zlocation-detail=none` 플래그가 설정됨 (바이너리 크기 최적화)
3. **증분 빌드**: `cargo build`는 변경된 크레이트만 다시 빌드하므로 빠름
4. **새 체인 추가 시**: `rust/chains/` 하위에 `tw_{chain_name}` 크레이트 생성, `Cargo.toml` 워크스페이스에 등록
