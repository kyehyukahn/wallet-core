# 606. Docker 빌드

Docker를 사용하여 일관된 Linux 빌드 환경을 구축하는 방법.

## 사전 조건

- Docker 설치

## Dockerfile 개요

프로젝트 루트의 `Dockerfile`은 Ubuntu 22.04 기반으로 전체 빌드 환경을 구성한다.

### 베이스 이미지 환경

| 항목 | 버전/설정 |
|------|----------|
| OS | Ubuntu 22.04 |
| C 컴파일러 | clang-14 |
| C++ 컴파일러 | clang++-14 |
| Rust | nightly-2025-12-11 |
| CMake | apt 기본 |
| Boost | libboost-all-dev |

### Docker 빌드 단계

```dockerfile
# 1. 시스템 패키지 설치
apt-get install build-essential clang-14 llvm-14 cmake libboost-all-dev ...

# 2. Rust 설치
wget "https://sh.rustup.rs" | sh
rustup default nightly-2025-12-11
cargo install cbindgen

# 3. C++ 의존성 빌드
tools/install-dependencies          # gtest, check, protobuf 빌드

# 4. 코드 생성 + Rust 빌드
tools/generate-files native

# 5. C++ 빌드
cmake -H. -Bbuild -DCMAKE_BUILD_TYPE=Debug
make -Cbuild -j12 TrustWalletCore

# 6. 테스트 바이너리 빌드
make -Cbuild -j12 tests
```

## Docker 빌드 실행

```bash
# 이미지 빌드
docker build -t wallet-core .

# 컨테이너에서 테스트 실행
docker run --rm wallet-core ./build/tests/tests

# 인터랙티브 셸
docker run -it --rm wallet-core /bin/bash
```

## 개발용 Docker 활용

소스 마운트를 통해 Docker 환경에서 개발:

```bash
# 소스를 마운트하여 인터랙티브 사용
docker run -it --rm \
    -v $(pwd):/wallet-core \
    -w /wallet-core \
    wallet-core /bin/bash

# 컨테이너 내부에서 빌드/테스트 반복
make -Cbuild -j12 tests && ./build/tests/tests
```

## 주의사항

1. **첫 빌드 시간**: Docker 이미지 빌드에 30분 이상 소요될 수 있음 (의존성 컴파일 포함)
2. **이미지 크기**: 전체 빌드 환경 포함 시 수 GB
3. **iOS 빌드 불가**: Docker (Linux)에서는 iOS/Swift 빌드 불가
4. **캐시 활용**: Docker layer 캐시를 위해 의존성 설치와 소스 빌드를 분리하면 좋음
