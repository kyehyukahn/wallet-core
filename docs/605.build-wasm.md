# 605. WASM / TypeScript 빌드

wallet-core를 웹 브라우저 및 Node.js에서 사용하기 위한 WebAssembly 빌드 가이드.

> **ℹ️ wasm 프로파일 = 서명 전용 (SPV 제외)**: wasm 빌드는 `wallet_core_rs`를
> `--no-default-features --features any-coin,bitcoin,ethereum,evm,keypair,solana,ton,utils`
> (= default에서 `spv`만 제외)로 빌드한다 (`tools/rust-bindgen`의 wasm 분기에 박힘).
> 이는 우회가 아니라 설계 결정이다:
>
> 1. **기술적**: `tw_spv`의 tokio-runtime → `mio`가 `wasm32-unknown-emscripten`
>    백엔드를 갖고 있지 않다 (컴파일 불가).
> 2. **구조적**: 브라우저는 raw TCP 소켓을 열 수 없어 Bitcoin P2P(8333)에
>    어차피 접속 불가 — async 런타임을 교체해도 동작할 수 없는 코드다.
>
> wasm에서 비트코인 **서명·주소·tx 빌드(`tw_bitcoin`) / HDWallet / 전 체인**은
> 전부 동작한다. 빠지는 것은 SPV 라이트 노드(`TWBitcoinWalletManager`,
> `TWBitcoinSpvSync`)뿐이며, 웹에서 체인 데이터가 필요하면 HTTP 인덱서/RPC를
> 사용한다 (업스트림 `@trustwallet/wallet-core`와 동일한 모델). codegen은 이미
> SPV 헤더 2개를 `SKIP_HEADERS`로 제외하므로 글루/링크 이슈가 없다.
> 장래 웹 SPV가 필요해지면 `tw_spv`의 `SpvRuntime` trait에 WebSocket+프록시
> 구현체를 추가하는 경로가 열려 있다 (별도 프로젝트 규모).
> 과거 진단 이력은 [607.build-troubleshooting.md](607.build-troubleshooting.md)의 WASM 절 참조.

## 사전 조건

- [600. 빌드 사전 준비](600-build-prerequisites.md) 완료
- Emscripten SDK (emsdk)

## Emscripten 설치

```bash
tools/install-wasm-dependencies
```

이 스크립트가 수행하는 작업:
1. **emsdk 4.0.22** 클론 및 설치 (`./emsdk/` 디렉토리에)
2. **Boost 헤더** 1.83.0 다운로드 (Emscripten sysroot에 설치)

> 설치 후 `emsdk/` 디렉토리가 프로젝트 루트에 생성됨.

## 빌드 흐름

```
tools/install-wasm-dependencies  ← Emscripten 설치 (최초 1회)
    ↓
tools/generate-files wasm        ← WASM 바인딩 + Rust WASM 크로스 컴파일
    ↓
tools/wasm-build                 ← C++ → WASM 컴파일 (cmake + emscripten)
    ↓
cd wasm && npm run build-and-test ← TypeScript 빌드 + 테스트
```

## Step 1: 코드 생성

```bash
tools/generate-files wasm
```

WASM 타겟 시 추가 수행:
1. **Rust WASM 크로스 컴파일** — `tools/rust-bindgen wasm`
   - `source emsdk/emsdk_env.sh` 후
   - `cargo build -Z build-std=std,panic_abort --target wasm32-unknown-emscripten --release --lib`
   - 출력: `rust/target/wasm32-unknown-emscripten/release/libwallet_core_rs.a`

## Step 2: C++ WASM 빌드

```bash
tools/wasm-build
```

내부적으로:
```bash
source emsdk/emsdk_env.sh

cmake -Bwasm-build \
    -DBoost_INCLUDE_DIR=${EMSDK}/upstream/emscripten/system/include \
    -DTW_COMPILE_WASM=ON \
    -DCMAKE_TOOLCHAIN_FILE=${EMSDK}/upstream/emscripten/cmake/Modules/Platform/Emscripten.cmake

make -j8 -Cwasm-build
```

`TW_COMPILE_WASM=ON` 시 CMake 동작:
- WASM용 Rust 라이브러리 경로 사용 (`wasm32-unknown-emscripten/release/`)
- `wasm/` 서브디렉토리 빌드 포함

빌드 결과: `wasm-build/` 디렉토리에 `.wasm` 및 JS 글루 코드 생성

## Step 3: TypeScript 빌드 & 테스트

```bash
cd wasm
npm install
npm run build-and-test
```

### 테스트 프레임워크

- **mocha** 기반
- 테스트 위치: `wasm/tests/Blockchain/`

## Rust WASM 테스트 (별도)

Rust 크레이트를 WASM 환경에서 직접 테스트:

```bash
tools/rust-test wasm

# 내부적으로:
# source emsdk/emsdk_env.sh
# cd rust
# export CARGO_TARGET_WASM32_UNKNOWN_EMSCRIPTEN_RUNNER=node
# cargo test --target wasm32-unknown-emscripten --profile wasm-test --workspace --exclude wallet_core_bin
```

## 디렉토리 구조

```
wasm/
├── src/                    ← WASM C++ 바인딩 소스
├── tests/
│   └── Blockchain/         ← TypeScript 테스트 (mocha)
├── package.json
└── README.md

wasm-build/                 ← cmake WASM 빌드 출력
├── *.wasm
└── *.js                    ← Emscripten 글루 코드

emsdk/                      ← Emscripten SDK (git clone)
```

## NPM 패키지로 사용

```bash
npm install @trustwallet/wallet-core
```

또는 로컬 빌드 결과를 직접 사용:
```bash
cd wasm && npm pack
# 생성된 .tgz를 프로젝트에서 설치
npm install /path/to/trustwallet-wallet-core-x.y.z.tgz
```

## 주의사항

1. **emsdk 환경변수**: 빌드 전에 반드시 `source emsdk/emsdk_env.sh` 필요 (scripts가 자동으로 수행)
2. **Boost 헤더**: Emscripten용 별도 Boost 헤더가 필요 (install-wasm-dependencies에서 설치)
3. **Node.js**: WASM 테스트 실행에 Node.js 필요
4. **빌드 디렉토리**: native(`build/`)와 WASM(`wasm-build/`)은 별도 디렉토리 사용
