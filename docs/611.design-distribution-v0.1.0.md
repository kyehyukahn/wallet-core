# wallet-core v0.1.0 — 배포 경로 정립 (npm wrapper + GitHub Packages)

**Date**: 2026-05-30
**Branch (wallet-core)**: `feature/release-v0.1.0-setup` (dev에서 분기, PR로 dev에 머지)
**Branch (cirqle-mobile)**: 별도 작은 PR로 121 docs 보강
**Scope**: 산출물(iOS xcframework + Android AAR) 배포 경로 정립. PR 2(config plugin + TurboModule 골격)는 다음 세션.

## 1. 배포 구조 (결정됨)

```
GitHub Releases (kyehyukahn/wallet-core)
  └─ v0.1.0/
      ├─ WalletCoreCommon.xcframework.zip    (~264 MB)
      ├─ WalletCoreRs.xcframework.zip        (~97 MB)
      ├─ wallet-core.aar                     (~29 MB)
      └─ SHA256SUMS

GitHub Packages npm registry (kyehyukahn 소유)
  └─ @kyehyukahn/wallet-core@0.1.0
      └─ 얇은 wrapper (postinstall이 위 Release 자산 다운+검증+풀기)

cirqle-mobile
  └─ pnpm add @kyehyukahn/wallet-core@^0.1.0
      → postinstall 자동 실행, node_modules에 native artifact 배치
      → 향후 PR 2의 config plugin이 이 경로를 참조
```

- 산출물 자체는 git tree 밖 (Releases가 호스팅).
- npm 패키지 가시성은 소스 리포가 PUBLIC이므로 자동 PUBLIC.
- 소비자 `.npmrc`: `@kyehyukahn:registry=https://npm.pkg.github.com` 한 줄.

## 2. wallet-core 측 신규 자산

```
tools/release-pack                          ← 산출물 패키징 스크립트

docs/610.distribution-npm-github-packages.md ← 다음 버전 절차서

```
