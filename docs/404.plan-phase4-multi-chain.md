# Phase 4: Multi-chain Expansion — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bitcoin Cash, Litecoin, Dogecoin에 대한 `SpvChain` + `WalletChain` 구현을 추가하여 기존 SPV/Wallet 인프라를 통해 다중 UTXO 체인을 지원한다.

**Architecture:** Phase 1~3에서 구축한 `SpvChain`/`WalletChain` trait의 확장점을 활용한다. 각 체인은 네트워크 파라미터(매직넘버, DNS 시드, 체크포인트, 포트), 난이도 검증 규칙, 지갑 정책(dust, gap limit, coin type)만 구현하면 된다. 핵심 SPV/Wallet 로직은 재사용한다. `ChainId` enum에 variant를 추가하고, 각 체인의 config 파일을 `tw_spv`와 `tw_wallet_manager`에 추가한다.

**Tech Stack:** Rust (edition 2021), `tw_spv` (SpvChain), `tw_wallet_manager` (WalletChain), `tw_hash` (scrypt for Litecoin/Dogecoin)

**Design Spec:** `docs/300.design_bitcoin_improvemet.md` — §14 (Multi-chain Expansion Plan), §6-3 (Recommended Traits), §15 Phase 4 testing

**Prerequisite:** Phase 1 (`tw_spv`) + Phase 2 (`tw_wallet_manager`) + Phase 3 (tx improvement) 완료.

pub struct BitcoinCashMainnet;

impl SpvChain for BitcoinCashMainnet {
    fn chain_id(&self) -> ChainId {
        ChainId::BitcoinCashMainnet
    }

    fn network_magic(&self) -> u32 {
        0xe8f3e1e3 // BCash mainnet magic
    }

    fn default_port(&self) -> u16 {
        8333
    }

    fn dns_seeds(&self) -> &'static [&'static str] {
        BCASH_MAINNET_DNS_SEEDS
    }

    fn checkpoints(&self) -> &[Checkpoint] {
        BCASH_MAINNET_CHECKPOINTS
    }

    fn min_protocol_version(&self) -> u32 {
        70015 // BCash requires newer protocol
    }

    fn protocol_version(&self) -> u32 {
        70015
    }

    fn supports_bloom_filtering(&self) -> bool {
        true
    }

    fn verify_header_chain(
        &self,
        _prev: &BlockHeader,
        current: &BlockHeader,
        _height: u32,
    ) -> Result<(), HeaderVerificationError> {
        if current.timestamp > current_timestamp() + MAX_FUTURE_BLOCK_TIME {
            return Err(HeaderVerificationError::TimestampTooFarInFuture);
        }
        // BCash DAA (D601) difficulty adjustment is complex and requires
        // access to the previous 144 blocks. Full verification is deferred
        // to the SyncManager which has access to the block set.
        // Here we only validate basic header integrity.
        Ok(())
    }
}

// SPDX-License-Identifier: Apache-2.0

use crate::wallet_chain::WalletChain;

/// Dogecoin mainnet wallet chain policy.
/// Dogecoin has higher typical amounts, so dust threshold is different.
/// Coin type 3 (SLIP44).
pub struct DogecoinMainnetWallet;

impl WalletChain for DogecoinMainnetWallet {
    fn external_gap_limit(&self) -> u32 {
        20
    }

    fn internal_gap_limit(&self) -> u32 {
        20
    }

    fn dust_threshold(&self, fee_rate: u64) -> u64 {
        // Dogecoin uses a fixed dust threshold of 1 DOGE = 100_000_000 shibes
        // This is much higher than Bitcoin due to Dogecoin's different economics.
        // Dogecoin Core uses a fixed 1 DOGE minimum output.
        let calculated = fee_rate * 3 * (34 + 148) / 1000;
        std::cmp::max(calculated, 100_000_000) // 1 DOGE minimum
    }

    fn max_reorg_depth(&self) -> u32 {
        6 // 1 minute blocks, so 6 confirmations = ~6 minutes
    }

    fn coin_type(&self) -> u32 {
        3 // SLIP44 for Dogecoin
    }
}

pub struct DogecoinTestnetWallet;

impl WalletChain for DogecoinTestnetWallet {
    fn external_gap_limit(&self) -> u32 {
        20
    }

    fn internal_gap_limit(&self) -> u32 {
        20
    }

    fn dust_threshold(&self, fee_rate: u64) -> u64 {
        let calculated = fee_rate * 3 * (34 + 148) / 1000;
        std::cmp::max(calculated, 100_000_000)
    }

    fn max_reorg_depth(&self) -> u32 {
        6
    }

    fn coin_type(&self) -> u32 {
        1
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_dogecoin_wallet_coin_type() {
        assert_eq!(DogecoinMainnetWallet.coin_type(), 3);
    }

    #[test]
    fn test_dogecoin_wallet_dust_minimum() {
        // Dogecoin dust minimum is 1 DOGE regardless of fee rate
        let dust = DogecoinMainnetWallet.dust_threshold(10000);
        assert_eq!(dust, 100_000_000); // 1 DOGE
    }

    #[test]
    fn test_dogecoin_wallet_dust_high_fee() {
        // Even at very high fee, dust should be at least 1 DOGE
