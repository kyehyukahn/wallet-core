# 500. FFI Integration + SpvRuntime — Design Spec

- **Date**: 2026-04-01
- **Status**: Approved
- **Prerequisite**: Phase 1~4 구현 완료 (`tw_spv`, `tw_wallet_manager`)

---

## 1. Goal

`tw_spv`와 `tw_wallet_manager`의 기능을 wallet-core C ABI를 통해 앱(iOS/Android/WASM)에 노출하고, tokio 기반 `SpvRuntime` 구현체를 추가하여 실제 Bitcoin testnet 연결까지 동작하도록 한다.

---

## 2. Scope

### In Scope

- `SpvRuntime`의 tokio 구현체 (`TokioRuntime`)
- `BitcoinWalletManager` FFI 함수 (생성, 잔액, 주소, 수수료, 저장/복원)
- `BitcoinSpvSync` FFI 함수 (동기화 시작/중지, 진행률, 피어 수)
- C 헤더 (`TWBitcoinWalletManager.h`, `TWBitcoinSpvSync.h`)
- `wallet_core_rs` Cargo.toml 의존성 추가

### Out of Scope

- Swift/Kotlin 바인딩 재생성 (`tools/generate-files` — 앱 통합 시점에 실행)
- 백그라운드 동기화 정책 (앱 레이어 관심사)
- Persistence 구현체 제공 (앱이 주입)

## 3. SpvRuntime — TokioRuntime

### 파일

`rust/frameworks/tw_spv/src/tokio_runtime.rs`

### 설계

```rust
pub struct TokioRuntime {
    rt: tokio::runtime::Runtime,
}

impl TokioRuntime {
    pub fn new() -> std::io::Result<Self> {
        let rt = tokio::runtime::Builder::new_multi_thread()
            .worker_threads(2)       // SPV에는 2 스레드면 충분
            .enable_all()            // io + time
            .build()?;
        Ok(TokioRuntime { rt })
    }

    /// 동기 컨텍스트에서 async 함수를 실행.
    /// FFI 함수에서 사용.
    pub fn block_on<F: std::future::Future>(&self, future: F) -> F::Output {
        self.rt.block_on(future)
    }
}

impl SpvRuntime for TokioRuntime {
    fn spawn(&self, task: BoxFuture) {
        self.rt.spawn(task);
    }
    fn spawn_blocking(&self, task: BoxFuture) {
        self.rt.spawn(task);  // tokio handles blocking internally
    }
    fn now(&self) -> SystemTime {
        SystemTime::now()
    }
}
```

### Cargo.toml

`tw_spv/Cargo.toml`에 tokio 의존 추가 (feature-gated):

```toml
[features]
default = []
tokio-runtime = ["tokio"]

[dependencies]
tokio = { version = "1", features = ["rt-multi-thread", "net", "time", "io-util"], optional = true }
```

앱이 tokio를 원하지 않으면 feature 없이 빌드할 수 있다.

## 4. FFI API — TWBitcoinWalletManager

### C 헤더

```c
TW_EXPORT_CLASS
struct TWBitcoinWalletManager;

// 생명주기
TWBitcoinWalletManager* TWBitcoinWalletManagerCreate(TWString* xpub);
void TWBitcoinWalletManagerDelete(TWBitcoinWalletManager* manager);
int TWBitcoinWalletManagerInitialize(TWBitcoinWalletManager* manager);

// 잔액/주소
uint64_t TWBitcoinWalletManagerBalance(TWBitcoinWalletManager* manager);
TWString* TWBitcoinWalletManagerReceiveAddress(TWBitcoinWalletManager* manager);
TWString* TWBitcoinWalletManagerChangeAddress(TWBitcoinWalletManager* manager);

// 수수료
uint64_t TWBitcoinWalletManagerFeeRate(TWBitcoinWalletManager* manager);
void TWBitcoinWalletManagerSetFeeRate(TWBitcoinWalletManager* manager, uint64_t feeRate);
uint64_t TWBitcoinWalletManagerEstimateFee(TWBitcoinWalletManager* manager, uint64_t amount);
uint64_t TWBitcoinWalletManagerMaxSpendable(TWBitcoinWalletManager* manager);
uint64_t TWBitcoinWalletManagerMinOutputAmount(TWBitcoinWalletManager* manager);

// 상태 저장
bool TWBitcoinWalletManagerSaveState(TWBitcoinWalletManager* manager);
```

### Rust FFI 패턴

기존 wallet-core 패턴을 따른다:
- `#[no_mangle] pub unsafe extern "C" fn`
- `TWString`, `TWData` 포인터 사용
- `try_or_else!` 매크로로 에러 핸들링
- `RawPtrTrait`로 메모리 관리

### FFI Handle

```rust
pub struct TWBitcoinWalletManagerImpl {
    manager: BitcoinWalletManager,
    persistence: Arc<InMemoryPersistence>,  // 기본 제공, 앱이 교체 가능
}

impl RawPtrTrait for TWBitcoinWalletManagerImpl {}
```
