# wallet-core 포크 빌드 환경 완성 — Design

**Date**: 2026-05-30
**Branch**: features/bitcoin_spv → dev (fast-forward)
**Scope**: 빌드 환경 + 빌드 관련 문서까지. RN 연동(TurboModule, cirqle 배포)은 별도 후속 브랜치.

## 1. 범위와 성공 기준

전 지원 플랫폼에 대해 현재 브랜치에서 빌드가 성공함을 검증하고, 빌드 가이드 문서를 commit, fast-forward로 dev에 반영한다.

| 플랫폼 | 산출물 | 검증 |
|---|---|---|
| iOS (device/sim/maccatalyst) | `WalletCoreCommon.xcframework` 4슬라이스 + `WalletCoreRs.xcframework` | `tools/ios-build` exit 0, 4슬라이스 확인 — **완료** |
| macOS | iOS xcframework의 macos-arm64_x86_64 슬라이스 | iOS 빌드와 함께 — **완료** |
| Android | `build/wallet-core.aar` (4 ABI) | `tools/android-build` exit 0 |
| wasm | wasm 정적 라이브러리 | `tools/rust-bindgen wasm` exit 0 (emsdk 필요) |

**범위 제외** (다음 브랜치): RN TurboModule, cirqle-mobile 배포 전략(GitHub Releases 등).

## 2. 커밋 구성 (3개, 분리)

**commit a — 빌드 패치**
- `swift/common-xcframework.yml`: `OTHER_CFLAGS`에 `-Wno-implicit-int-float-conversion` 추가
- 사유: 최신 clang(Xcode 16+)이 `Bitcoin/InputSelector.cpp:182`의 `int64_t→double` 암묵 변환을 `-Werror`로 승격시켜 archive 실패. 코드 변경 없이 toolchain 변화에 대응.

**commit b — docs/ 추가 (20개)**
- 200/300/310/400~404/410: 아키텍처·설계·계획 (Bitcoin SPV 관련)
- 600~608: 플랫폼별 빌드 가이드
- 800/900: TODO / 라이선스 운영
- `607.build-troubleshooting.md`에 본 세션에서 확인된 두 막힘 기록:
  1. `-Werror` float 변환 (→ commit a로 해결)
  2. `tools/rust-bindgen ios` → `tools/ios-build` 의존 순서
- 측정 크기는 `603` 또는 `608`의 "산출물 크기" 절로 기록 (다음 브랜치의 배포 결정 근거).

**commit c — misc**
- LICENSE-3RD-PARTY.txt, codegen/{bin/coins, lib/coin_skeleton_gen.rb, lib/coin_test_gen.rb}, rust/wallet_core_rs/src/ffi/mod.rs, samples/android/gradle/wrapper/gradle-wrapper.properties

`kotlin/build-logic/bin/`는 빌드 산출물 디렉터리로 커밋하지 않음.

master/prod 변경 없음.

## 4. 실행 순서

1. **iOS 빌드 검증** — 완료 (`WalletCoreCommon.xcframework` 264MB, `WalletCoreRs.xcframework` 97MB)
2. **Android AAR 빌드** — `tools/install-android-dependencies` → `tools/generate-files android` → `tools/android-build`, 산출물·크기 측정
3. **wasm 빌드** — `tools/install-wasm-dependencies`(emsdk) → `tools/rust-bindgen wasm`
4. **문서 완성도 점검** — 600~607 placeholder 스캔, 측정 크기 / 막힘 사항 반영
5. **3개 commit** 작성
6. **fast-forward 머지** dev로
7. **푸시** features/bitcoin_spv + dev

검증 중 새로운 빌드 막힘 발견 시: 코드 패치 필요한 경우 commit a에 추가, 환경 설정 누락이면 607에 기록.
