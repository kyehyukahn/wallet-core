# 603. iOS / macOS 빌드

wallet-core를 iOS/macOS 앱에서 사용하기 위한 Swift 바인딩 빌드 가이드.

## 사전 조건

- macOS 필수 (Xcode 필요)
- [600. 빌드 사전 준비](600-build-prerequisites.md) 완료
- 추가 도구: `xcodegen`, `xcbeautify` (brew로 설치됨)
- `protoc-gen-swift` 빌드 완료 (`tools/install-dependencies`에서 자동 빌드)

## 빌드 흐름

```
bootstrap.sh ios
    ↓
tools/generate-files ios        ← Swift protobuf + Xcode 프로젝트 생성
    ↓
tools/ios-build                 ← xcframework 빌드
    또는
tools/ios-test                  ← 시뮬레이터에서 테스트
```

## Step 1: 코드 생성

```bash
tools/generate-files ios
```

iOS 타겟 시 추가로 수행되는 작업:
1. **Rust iOS 크로스 컴파일** — `tools/rust-bindgen ios`
   - aarch64-apple-ios (실제 디바이스)
   - aarch64-apple-ios-sim + x86_64-apple-ios (시뮬레이터)
   - aarch64-apple-darwin + x86_64-apple-darwin (macOS)
   - Mac Catalyst 타겟
   - lipo로 Universal Binary 생성
   - **WalletCoreRs.xcframework** 생성 (`swift/WalletCoreRs.xcframework`)
2. **Swift Protobuf 코드 생성** — `protoc --swift_out`
   - `SwiftProtobuf` import를 `WalletCoreSwiftProtobuf`로 자동 치환
3. **Xcode 프로젝트 생성** — `tools/xcodegen`

## Step 2: 테스트

```bash
tools/ios-test
```

내부적으로:
```bash
cd swift
xcodebuild -workspace TrustWalletCore.xcworkspace \
    -scheme WalletCore \
    -sdk iphonesimulator \
    -destination "platform=iOS Simulator,name=iPhone 16,OS=18.5" \
    test | xcbeautify
```

> 시뮬레이터 이름/OS 버전은 설치된 Xcode/시뮬레이터에 맞게 수정 필요할 수 있음.

## Step 3: XCFramework 빌드 (배포용)

```bash
tools/ios-build
```

이 스크립트는 **WalletCoreCommon** xcframework를 생성한다:

| 아키텍처 | 용도 |
|----------|------|
| ios-arm64 | iPhone 실제 디바이스 |
| ios-arm64_x86_64-simulator | iOS 시뮬레이터 |
| ios-x86_64_arm64-maccatalyst | Mac Catalyst |
| macos-arm64_x86_64 | macOS 네이티브 |

빌드 결과: `build/ios-frameworks/WalletCoreCommon.xcframework`

### 산출물 크기 참고

본 포크 기준 release 정적 프레임워크 측정값 (Xcode 16+, Apple Silicon Mac):

| 산출물 | 슬라이스 | 크기 |
|---|---|---|
| `WalletCoreCommon.xcframework` | ios-arm64 (기기, 1-arch) | ~37 MB |
| | ios-arm64_x86_64-simulator | ~73 MB |
| | ios-arm64_x86_64-maccatalyst | ~77 MB |
| | macos-arm64_x86_64 | ~77 MB |
| | **합계** | **~264 MB** |
| `WalletCoreRs.xcframework` | 4슬라이스 (위와 동일 구성) | ~97 MB |
| **iOS 네이티브 합계** | | **~361 MB** |

크기는 디스크상 정적 라이브러리 + 디버그 심볼 포함 크기로, 앱에 링크되어 배포될 때는
dead-code stripping과 단일 아키텍처 추출이 적용돼 훨씬 작아진다 (앱 바이너리 기여분은
일반적으로 십수 MB 수준). xcframework 자체를 git 저장소에 직접 두는 것은 GitHub의
파일당 100 MB 한도를 초과하므로, **별도 배포(예: GitHub Releases) 또는 빌드 시 로컬 생성**
방식을 권장한다.

## 생성되는 Swift 파일 구조

```
swift/
├── Sources/
│   ├── Generated/
│   │   ├── Protobuf/          ← protoc-gen-swift 생성 (편집 금지)
│   │   └── Enums/             ← codegen 생성 (편집 금지)
│   └── ...                    ← 수동 작성 Swift 래퍼
├── Tests/                     ← Swift 단위 테스트
├── TrustWalletCore.xcworkspace
├── WalletCoreRs.xcframework   ← Rust 라이브러리 xcframework
└── cpp.xcconfig               ← C++ 빌드 설정 (cmake에서 생성)
```

## 앱에서 사용하기

### Swift Package Manager (SPM)

```swift
// Package.swift
.package(name: "WalletCore", path: "../WalletCore"),

// 또는 원격
.package(name: "WalletCore", url: "https://github.com/trustwallet/wallet-core", .branch("master")),
```

타겟 의존성에 추가:
```swift
.product(name: "WalletCore", package: "WalletCore"),
.product(name: "WalletCoreSwiftProtobuf", package: "WalletCore"),
```

### CocoaPods

```ruby
pod 'TrustWalletCore'
```

## 주의사항

1. **Generated 파일 편집 금지**: `swift/Sources/Generated/` 하위 파일은 자동 생성됨
2. **WalletCoreSwiftProtobuf**: Swift Protobuf를 래핑한 별도 모듈. `SwiftProtobuf` 대신 이것을 import
3. **시뮬레이터 버전**: `tools/ios-test`의 시뮬레이터 설정이 현재 환경과 맞지 않으면 수정 필요
4. **Rust xcframework**: `tools/rust-bindgen ios`가 Rust 라이브러리의 xcframework도 함께 생성
