# Phase 1: Bitcoin SPV Foundation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bitcoin mainnet/testnet에 P2P로 직접 연결하여 header sync 및 BIP37 filtered block sync를 수행하는 `tw_spv` Rust crate를 구현한다.

**Architecture:** `tw_spv`는 `rust/frameworks/` 아래 신규 crate로 생성된다. 기존 `tw_utxo`의 `Encodable` trait, `Stream`, `CompactInteger`, `H256` 등을 재사용하고, 역직렬화를 위한 `Decodable` trait을 새로 도입한다. 핵심 컴포넌트는 BloomFilter → MerkleBlock → Messages → Peer → PeerManager → SyncManager 순으로 상향식 구축한다.

**Tech Stack:** Rust (edition 2021), `tw_hash` (SHA256d, MurmurHash3), `tw_utxo` (Encodable, CompactInteger, H256), `tw_encoding` (hex)

**Design Spec:** `docs/300.design_bitcoin_improvemet.md`

**Scope:** 이 계획은 Phase 1만 다룬다. Phase 2 (Wallet Manager), Phase 3 (Transaction improvement), Phase 4 (Multi-chain)는 별도 계획으로 작성한다.

```rust
// rust/frameworks/tw_spv/src/error.rs
// SPDX-License-Identifier: Apache-2.0

use std::fmt;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SpvError {
    /// Not enough data to decode a structure.
    UnexpectedEof,
    /// Decoded value violates a protocol rule.
    InvalidData(String),
    /// Checksum mismatch in message header.
    ChecksumMismatch,
    /// Message exceeds maximum allowed size.
    MessageTooLarge,
    /// Unknown or unsupported message command.
    UnknownCommand(String),
}

impl fmt::Display for SpvError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            SpvError::UnexpectedEof => write!(f, "unexpected end of data"),
            SpvError::InvalidData(msg) => write!(f, "invalid data: {}", msg),
            SpvError::ChecksumMismatch => write!(f, "checksum mismatch"),
            SpvError::MessageTooLarge => write!(f, "message too large"),
            SpvError::UnknownCommand(cmd) => write!(f, "unknown command: {}", cmd),
        }
    }
}

impl std::error::Error for SpvError {}

pub type SpvResult<T> = Result<T, SpvError>;
```

```rust
// rust/frameworks/tw_spv/src/decode/reader.rs
// SPDX-License-Identifier: Apache-2.0

use crate::error::{SpvError, SpvResult};
use byteorder::{LittleEndian, ReadBytesExt};
use std::io::Cursor;
use tw_hash::H256;

/// A cursor-based reader for deserializing Bitcoin wire format data.
pub struct Reader<'a> {
    cursor: Cursor<&'a [u8]>,
}

impl<'a> Reader<'a> {
    pub fn new(data: &'a [u8]) -> Self {
        Reader {
            cursor: Cursor::new(data),
        }
    }

    pub fn position(&self) -> usize {
        self.cursor.position() as usize
    }

    pub fn remaining(&self) -> usize {
        let pos = self.cursor.position() as usize;
        let len = self.cursor.get_ref().len();
        len.saturating_sub(pos)
    }

    pub fn is_empty(&self) -> bool {
        self.remaining() == 0
    }

    pub fn read_u8(&mut self) -> SpvResult<u8> {
        self.cursor.read_u8().map_err(|_| SpvError::UnexpectedEof)
    }

    pub fn read_u16_le(&mut self) -> SpvResult<u16> {
        self.cursor
            .read_u16::<LittleEndian>()
            .map_err(|_| SpvError::UnexpectedEof)
    }

    /// Read a big-endian u16. Used for network port fields in Bitcoin P2P
    /// protocol, which are in network byte order (big-endian) unlike most
    /// other fields.
    pub fn read_u16_be(&mut self) -> SpvResult<u16> {
        self.cursor
            .read_u16::<byteorder::BigEndian>()
            .map_err(|_| SpvError::UnexpectedEof)
    }

    pub fn read_u32_le(&mut self) -> SpvResult<u32> {
        self.cursor
            .read_u32::<LittleEndian>()
            .map_err(|_| SpvError::UnexpectedEof)
    }

    pub fn read_i32_le(&mut self) -> SpvResult<i32> {
        self.cursor
            .read_i32::<LittleEndian>()
            .map_err(|_| SpvError::UnexpectedEof)
    }

    pub fn read_u64_le(&mut self) -> SpvResult<u64> {
        self.cursor
            .read_u64::<LittleEndian>()
            .map_err(|_| SpvError::UnexpectedEof)
    }

    pub fn read_i64_le(&mut self) -> SpvResult<i64> {
        self.cursor
            .read_i64::<LittleEndian>()
            .map_err(|_| SpvError::UnexpectedEof)
    }

    pub fn read_bytes(&mut self, len: usize) -> SpvResult<Vec<u8>> {
        if self.remaining() < len {
            return Err(SpvError::UnexpectedEof);
        }
        let pos = self.cursor.position() as usize;
        let data = self.cursor.get_ref()[pos..pos + len].to_vec();
        self.cursor.set_position((pos + len) as u64);
        Ok(data)
    }

    pub fn read_h256(&mut self) -> SpvResult<H256> {
        let bytes = self.read_bytes(32)?;
        let mut arr = [0u8; 32];
        arr.copy_from_slice(&bytes);
        Ok(H256::from(arr))
    }

    /// Read a Bitcoin compact integer (variable-length integer).
    pub fn read_compact_int(&mut self) -> SpvResult<u64> {
        let first = self.read_u8()?;
        match first {
            0x00..=0xFC => Ok(first as u64),
            0xFD => self.read_u16_le().map(|v| v as u64),
            0xFE => self.read_u32_le().map(|v| v as u64),
            0xFF => self.read_u64_le(),
        }
    }

    /// Read a variable-length byte string (compact int length prefix + data).
    pub fn read_var_bytes(&mut self) -> SpvResult<Vec<u8>> {
        let len = self.read_compact_int()? as usize;
        self.read_bytes(len)
    }

    /// Read a fixed-size string padded with null bytes (used in message headers).
    pub fn read_fixed_string(&mut self, len: usize) -> SpvResult<String> {
        let bytes = self.read_bytes(len)?;
        let end = bytes.iter().position(|&b| b == 0).unwrap_or(len);
        String::from_utf8(bytes[..end].to_vec())
            .map_err(|_| SpvError::InvalidData("invalid utf8 in fixed string".into()))
    }
}

    }
```

        70002
    }

    fn protocol_version(&self) -> u32 {
        70013
    }

    fn supports_bloom_filtering(&self) -> bool {
        true
    }

    fn verify_header_chain(
        &self,
        prev: &BlockHeader,
        current: &BlockHeader,
        height: u32,
    ) -> Result<(), HeaderVerificationError> {
        // 1. Timestamp validation: block timestamp must not be more than 2 hours in the future.
        let now = std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .unwrap_or_default()
            .as_secs() as u32;
        if current.timestamp > now + 2 * 60 * 60 {
            return Err(HeaderVerificationError::TimestampTooFarInFuture);
        }

        // 2. Basic difficulty guard: reject headers with suspiciously low difficulty.
        //    Bitcoin's retarget rule allows at most 4x difficulty decrease per period.
        //    We check: current target must not be more than 4x easier than prev target.
        //    This prevents an attacker from injecting a fake chain with trivial PoW.
        //
        //    NOTE: This is a simplified guard, not the full 2016-block retarget algorithm.
        //    The full algorithm requires the header at (height - 2016), which we may not
        //    have during initial sync. This guard catches the most obvious attacks.
        if height > 0 && prev.target != 0 {
            let prev_target = Self::compact_to_work(prev.target);
            let curr_target = Self::compact_to_work(current.target);
            // If current target is >4x the previous target (i.e., difficulty dropped
            // by more than 4x), reject it. In normal operation, this never happens
            // outside of retarget boundaries, and even then, the 4x limit holds.
            if curr_target > 0 && prev_target > 0 && curr_target > prev_target * 4 {
                return Err(HeaderVerificationError::InvalidDifficulty);
            }
        }

        // 3. Verify proof-of-work: block hash must be <= stated target.
        //    This ensures the miner actually did the work claimed by nBits.
        let block_hash = current.block_hash();
        let target_bytes = crate::merkle_block::MerkleBlock::target_to_u256(current.target);
        let hash_bytes = crate::merkle_block::MerkleBlock::hash_to_u256(&block_hash);
        if hash_bytes > target_bytes {
            return Err(HeaderVerificationError::InvalidProofOfWork);
        }

        Ok(())
    }

    /// Helper: extract approximate work value from compact target for comparison.
    /// Higher value = easier target = less work required.
    fn compact_to_work(n_bits: u32) -> u64 {
        let exponent = (n_bits >> 24) as u64;
        let mantissa = (n_bits & 0x7FFFFF) as u64;
        if exponent <= 3 {
            mantissa >> (8 * (3 - exponent))
        } else {
            mantissa << (8 * (exponent - 3))
        }
    }
}

```rust
// rust/frameworks/tw_spv/src/bloom_filter.rs (prepend before tests)
// SPDX-License-Identifier: Apache-2.0

use crate::decode::Reader;
use crate::error::{SpvError, SpvResult};
use tw_utxo::encode::compact_integer::CompactInteger;
use tw_utxo::encode::stream::Stream;
use tw_utxo::encode::Encodable;

/// BIP37 maximum filter length in bytes.
pub const BLOOM_MAX_FILTER_LENGTH: usize = 36000;
/// Maximum number of hash functions.
const BLOOM_MAX_HASH_FUNCS: u32 = 50;
/// Constant used in MurmurHash3 as per BIP37.
const MURMUR3_SEED_MULTIPLIER: u32 = 0xFBA4C795;

/// Bloom filter update policy (BIP37).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum UpdateType {
    None = 0,
    All = 1,
    P2PubkeyOnly = 2,
}

impl TryFrom<u8> for UpdateType {
    type Error = SpvError;

    fn try_from(value: u8) -> Result<Self, Self::Error> {
        match value {
            0 => Ok(UpdateType::None),
            1 => Ok(UpdateType::All),
            2 => Ok(UpdateType::P2PubkeyOnly),
            _ => Err(SpvError::InvalidData(format!(
                "invalid bloom filter update type: {}",
                value
            ))),
        }
    }
}

/// BIP37 Bloom Filter.
/// Algorithm matches breadwallet-core BRBloomFilter.c exactly.
#[derive(Debug, Clone)]
pub struct BloomFilter {
    pub filter: Vec<u8>,
    pub hash_funcs: u32,
    pub tweak: u32,
    pub flags: UpdateType,
    pub elem_count: usize,
}

impl BloomFilter {
    /// Create a new bloom filter.
    ///
    /// - `fp_rate`: desired false positive rate (e.g. 0.0005)
    /// - `elem_count`: expected number of elements
    /// - `tweak`: random nonce for hash function seed
    /// - `flags`: update policy
    ///
    /// Size and hash function count are calculated per BIP37 spec,
    /// matching breadwallet-core BRBloomFilterNew().
    pub fn new(fp_rate: f64, elem_count: usize, tweak: u32, flags: UpdateType) -> Self {
        let fp_rate = if fp_rate < 1e-9 { 1e-9 } else { fp_rate };

        // filter size in bytes: min(-1.0 / LN2^2 * n * ln(p) / 8, MAX)
        let ln2 = std::f64::consts::LN_2;
        let ln2_sq = ln2 * ln2;
        let size = std::cmp::min(
            ((-1.0 / ln2_sq * elem_count as f64 * fp_rate.ln()) / 8.0) as usize,
            BLOOM_MAX_FILTER_LENGTH,
        );
        let size = std::cmp::max(size, 1);

        // number of hash functions: filter_size_bits / elem_count * LN2
        let hash_funcs = if elem_count > 0 {
            std::cmp::min(
                ((size * 8) as f64 / elem_count as f64 * ln2) as u32,
                BLOOM_MAX_HASH_FUNCS,
            )
        } else {
            0
        };

        BloomFilter {
            filter: vec![0u8; size],
            hash_funcs,
            tweak,
            flags,
            elem_count: 0,
        }
    }

    /// MurmurHash3 (32-bit) as specified in BIP37.
    /// Matches breadwallet-core's implementation.
    fn murmur3_32(data: &[u8], seed: u32) -> u32 {
        let mut h1 = seed;
        let c1: u32 = 0xCC9E2D51;
        let c2: u32 = 0x1B873593;
        let len = data.len();
        let n_blocks = len / 4;

        // body
        for i in 0..n_blocks {
            let offset = i * 4;
            let mut k1 = u32::from_le_bytes([
                data[offset],
                data[offset + 1],
                data[offset + 2],
                data[offset + 3],
            ]);
            k1 = k1.wrapping_mul(c1);
            k1 = k1.rotate_left(15);
            k1 = k1.wrapping_mul(c2);
            h1 ^= k1;
            h1 = h1.rotate_left(13);
            h1 = h1.wrapping_mul(5).wrapping_add(0xE6546B64);
        }

        // tail
        let tail = &data[n_blocks * 4..];
        let mut k1: u32 = 0;
        match tail.len() {
            3 => {
                k1 ^= (tail[2] as u32) << 16;
                k1 ^= (tail[1] as u32) << 8;
                k1 ^= tail[0] as u32;
                k1 = k1.wrapping_mul(c1);
                k1 = k1.rotate_left(15);
                k1 = k1.wrapping_mul(c2);
                h1 ^= k1;
            }
            2 => {
                k1 ^= (tail[1] as u32) << 8;
                k1 ^= tail[0] as u32;
                k1 = k1.wrapping_mul(c1);
                k1 = k1.rotate_left(15);
                k1 = k1.wrapping_mul(c2);
                h1 ^= k1;
            }
            1 => {
                k1 ^= tail[0] as u32;
                k1 = k1.wrapping_mul(c1);
                k1 = k1.rotate_left(15);
                k1 = k1.wrapping_mul(c2);
                h1 ^= k1;
            }
            _ => {}
        }

        // finalization
        h1 ^= len as u32;
        h1 ^= h1 >> 16;
        h1 = h1.wrapping_mul(0x85EBCA6B);
        h1 ^= h1 >> 13;
        h1 = h1.wrapping_mul(0xC2B2AE35);
        h1 ^= h1 >> 16;

        h1
    }

    /// Compute the hash for element `data` using hash function index `i`.
    fn hash(&self, data: &[u8], i: u32) -> u32 {
        let seed = i.wrapping_mul(MURMUR3_SEED_MULTIPLIER).wrapping_add(self.tweak);
        Self::murmur3_32(data, seed) % (self.filter.len() as u32 * 8)
    }

    /// Insert an element into the filter.
    pub fn insert(&mut self, data: &[u8]) {
        for i in 0..self.hash_funcs {
            let bit = self.hash(data, i);
            self.filter[(bit >> 3) as usize] |= 1 << (bit & 7);
        }
        self.elem_count += 1;
    }

    /// Test if an element is (probably) in the filter.
    pub fn contains(&self, data: &[u8]) -> bool {
        for i in 0..self.hash_funcs {
            let bit = self.hash(data, i);
            if self.filter[(bit >> 3) as usize] & (1 << (bit & 7)) == 0 {
                return false;
            }
        }
        true
    }

    /// Serialize the bloom filter to Bitcoin wire format (for filterload message).
    ///
    /// Wire format: compact_int(filter_len) || filter_bytes || hash_funcs(u32le) || tweak(u32le) || flags(u8)
    ///
    /// NOTE: We explicitly write the compact integer length prefix + raw bytes
    /// rather than relying on `Encodable for Vec<u8>`, to ensure the wire format
    /// matches BIP37 exactly regardless of how tw_utxo implements Vec<u8> encoding.
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        // Explicit length-prefixed filter bytes (BIP37 wire format)
        stream.append(&CompactInteger::from(self.filter.len()));
        stream.append_raw_slice(&self.filter);
        stream.append(&self.hash_funcs);
        stream.append(&self.tweak);
        stream.append(&(self.flags as u8));
        stream.out()
    }

    /// Parse a bloom filter from Bitcoin wire format.
    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let filter = reader.read_var_bytes()?;
        if filter.len() > BLOOM_MAX_FILTER_LENGTH {
            return Err(SpvError::InvalidData("bloom filter too large".into()));
        }
        let hash_funcs = reader.read_u32_le()?;
        if hash_funcs > BLOOM_MAX_HASH_FUNCS {
            return Err(SpvError::InvalidData("too many hash functions".into()));
        }
        let tweak = reader.read_u32_le()?;
        let flags_byte = reader.read_u8()?;
        let flags = UpdateType::try_from(flags_byte)?;

        Ok(BloomFilter {
            filter,
            hash_funcs,
            tweak,
            flags,
            elem_count: 0,
        })
    }
}
```

```rust
// rust/frameworks/tw_spv/src/merkle_block.rs
// SPDX-License-Identifier: Apache-2.0

use crate::chain::BlockHeader;
use crate::decode::{Decodable, Reader};
use crate::error::{SpvError, SpvResult};
use tw_hash::sha2::sha256_d;
use tw_hash::H256;

/// Maximum time drift allowed for block timestamps (2 hours).
const BLOCK_MAX_TIME_DRIFT: u32 = 2 * 60 * 60;

/// A merkle block as received via the Bitcoin P2P protocol.
/// Contains a block header plus a partial merkle tree proving
/// which transactions matched the bloom filter.
///
/// Algorithm matches breadwallet-core BRMerkleBlock exactly.
#[derive(Debug, Clone)]
pub struct MerkleBlock {
    pub header: BlockHeader,
    pub total_tx: u32,
    pub hashes: Vec<H256>,
    pub flags: Vec<u8>,
    pub height: u32,
}

impl MerkleBlock {
    /// Parse a merkle block from wire format.
    /// If `buf` is exactly 80 bytes, it's treated as a header-only block.
    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let header = BlockHeader::decode(&mut reader)?;

        if reader.is_empty() {
            // Header-only (from headers message)
            return Ok(MerkleBlock {
                header,
                total_tx: 0,
                hashes: Vec::new(),
                flags: Vec::new(),
                height: u32::MAX,
            });
        }

        let total_tx = reader.read_u32_le()?;
        let hash_count = reader.read_compact_int()? as usize;
        let mut hashes = Vec::with_capacity(hash_count);
        for _ in 0..hash_count {
            hashes.push(reader.read_h256()?);
        }
        let flags = reader.read_var_bytes()?;

        Ok(MerkleBlock {
            header,
            total_tx,
            hashes,
            flags,
            height: u32::MAX, // set by caller after chain validation
        })
    }

    /// Compute the block hash (double SHA256 of the 80-byte header).
    pub fn block_hash(&self) -> H256 {
        self.header.block_hash()
    }

    /// Extract transaction hashes that matched the bloom filter.
    /// Returns the list of matched tx hashes if the merkle tree is valid,
    /// or an error if the proof is invalid.
    ///
    /// Algorithm matches breadwallet-core BRMerkleBlockTxHashes().
    pub fn matched_tx_hashes(&self) -> SpvResult<Vec<H256>> {
        if self.total_tx == 0 {
            return Ok(Vec::new());
        }

        let mut matched = Vec::new();
        let mut bit_idx: usize = 0;
        let mut hash_idx: usize = 0;

        let root = self.walk_tree(
            0,
            self.tree_height(),
            &mut bit_idx,
            &mut hash_idx,
            &mut matched,
        )?;

        // Verify computed root matches header's merkle root
        if root != self.header.merkle_root {
            return Err(SpvError::InvalidData(
                "merkle root mismatch".into(),
            ));
        }

        // All hashes and bits should be consumed
        if hash_idx != self.hashes.len() {
            return Err(SpvError::InvalidData(
                "not all hashes consumed".into(),
            ));
        }

        Ok(matched)
    }

    /// Validate the block: merkle tree valid, timestamp not too far in future,
    /// and proof-of-work matches stated difficulty target.
    ///
    /// NOTE: This does NOT verify the target is correct for the block's height —
    /// use SpvChain::verify_header_chain() for that.
    ///
    /// Matches breadwallet-core BRMerkleBlockIsValid().
    pub fn is_valid(&self, current_time: u32) -> SpvResult<bool> {
        // Check timestamp drift
        if self.header.timestamp > current_time + BLOCK_MAX_TIME_DRIFT {
            return Ok(false);
        }

        // Verify proof-of-work
        let hash = self.block_hash();
        let target = Self::target_to_u256(self.header.target);
        let hash_val = Self::hash_to_u256(&hash);
        if hash_val > target {
            return Ok(false);
        }

        // Verify merkle tree (if this is a full merkle block, not header-only)
        if self.total_tx > 0 {
            self.matched_tx_hashes()?;
        }

        Ok(true)
    }

    /// True if the given tx hash is included in the matched set.
    pub fn contains_tx_hash(&self, tx_hash: &H256) -> SpvResult<bool> {
        let matched = self.matched_tx_hashes()?;
        Ok(matched.contains(tx_hash))
    }

    // --- Internal merkle tree traversal ---

    fn tree_height(&self) -> usize {
        let mut h = 0;
        let mut count = self.total_tx as usize;
        while count > 1 {
            count = (count + 1) / 2;
            h += 1;
        }
        h
    }

    fn tree_width(&self, height: usize) -> usize {
        let total = self.total_tx as usize;
        (total + (1 << height) - 1) >> height
    }

    fn walk_tree(
        &self,
        pos: usize,
        height: usize,
        bit_idx: &mut usize,
        hash_idx: &mut usize,
        matched: &mut Vec<H256>,
    ) -> SpvResult<H256> {
        let is_parent = self.read_flag_bit(bit_idx)?;

        if height == 0 || !is_parent {
            // Leaf node or non-matching subtree — consume next hash.
            if *hash_idx >= self.hashes.len() {
                return Err(SpvError::InvalidData("hash index out of bounds".into()));
            }
            let hash = self.hashes[*hash_idx];
            *hash_idx += 1;

            if height == 0 && is_parent {
                matched.push(hash);
            }

            return Ok(hash);
        }

        // Internal node — recurse into children.
        let left = self.walk_tree(pos * 2, height - 1, bit_idx, hash_idx, matched)?;

        let right = if pos * 2 + 1 < self.tree_width(height - 1) {
            self.walk_tree(pos * 2 + 1, height - 1, bit_idx, hash_idx, matched)?
        } else {
            left // duplicate left child if there's no right child
        };

        // Combine children: SHA256d(left || right)
        let mut combined = Vec::with_capacity(64);
        combined.extend_from_slice(left.as_slice());
        combined.extend_from_slice(right.as_slice());
        let parent_hash = sha256_d(&combined);
        let mut arr = [0u8; 32];
        arr.copy_from_slice(&parent_hash);
        Ok(H256::from(arr))
    }

    fn read_flag_bit(&self, bit_idx: &mut usize) -> SpvResult<bool> {
        let byte_pos = *bit_idx / 8;
        let bit_pos = *bit_idx % 8;
        if byte_pos >= self.flags.len() {
            return Err(SpvError::InvalidData("flag bits exhausted".into()));
        }
        let result = (self.flags[byte_pos] >> bit_pos) & 1 == 1;
        *bit_idx += 1;
        Ok(result)
    }

    /// Convert compact target (nBits) to 256-bit integer for PoW comparison.
    fn target_to_u256(n_bits: u32) -> [u8; 32] {
        let mut target = [0u8; 32];
        let exponent = ((n_bits >> 24) & 0xFF) as usize;
        let mantissa = n_bits & 0x7FFFFF;

        if exponent >= 3 && exponent <= 32 {
            let start = 32 - exponent;
            target[start] = ((mantissa >> 16) & 0xFF) as u8;
            if start + 1 < 32 {
                target[start + 1] = ((mantissa >> 8) & 0xFF) as u8;
            }
            if start + 2 < 32 {
                target[start + 2] = (mantissa & 0xFF) as u8;
            }
        }

        target
    }

    /// Convert H256 hash to big-endian 32-byte array for comparison.
    fn hash_to_u256(hash: &H256) -> [u8; 32] {
        let mut arr = [0u8; 32];
        let bytes = hash.as_slice();
        // Bitcoin hashes are stored in little-endian; convert to big-endian for comparison
        for i in 0..32 {
            arr[i] = bytes[31 - i];
        }
        arr
    }
}
```

```rust
// rust/frameworks/tw_spv/src/messages/header.rs
// SPDX-License-Identifier: Apache-2.0

use crate::decode::Reader;
use crate::error::{SpvError, SpvResult};
use tw_hash::sha2::sha256_d;
use tw_utxo::encode::stream::Stream;
use tw_utxo::encode::Encodable;

/// Bitcoin P2P message header: 24 bytes.
/// magic(4) + command(12) + length(4) + checksum(4)
pub const MESSAGE_HEADER_SIZE: usize = 24;
/// Maximum message payload size (32 MB).
pub const MAX_MSG_LENGTH: u32 = 0x02000000;

#[derive(Debug, Clone)]
pub struct MessageHeader {
    pub magic: u32,
    pub command: String,
    pub payload_length: u32,
    pub checksum: [u8; 4],
}

impl MessageHeader {
    /// Create a message header for the given command and payload.
    pub fn new(magic: u32, command: &str, payload: &[u8]) -> Self {
        let hash = sha256_d(payload);
        let mut checksum = [0u8; 4];
        checksum.copy_from_slice(&hash[..4]);

        MessageHeader {
            magic,
            command: command.to_string(),
            payload_length: payload.len() as u32,
            checksum,
        }
    }

    /// Serialize the 24-byte header.
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        stream.append(&self.magic);

        // Command: 12 bytes, null-padded
        let mut cmd_bytes = [0u8; 12];
        let cmd = self.command.as_bytes();
        let len = std::cmp::min(cmd.len(), 12);
        cmd_bytes[..len].copy_from_slice(&cmd[..len]);
        stream.append_raw_slice(&cmd_bytes);

        stream.append(&self.payload_length);
        stream.append_raw_slice(&self.checksum);
        stream.out()
    }

    /// Parse a 24-byte header from raw bytes.
    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        if data.len() < MESSAGE_HEADER_SIZE {
            return Err(SpvError::UnexpectedEof);
        }
        let mut reader = Reader::new(data);
        let magic = reader.read_u32_le()?;
        let command = reader.read_fixed_string(12)?;
        let payload_length = reader.read_u32_le()?;
        let checksum_bytes = reader.read_bytes(4)?;
        let mut checksum = [0u8; 4];
        checksum.copy_from_slice(&checksum_bytes);

        if payload_length > MAX_MSG_LENGTH {
            return Err(SpvError::MessageTooLarge);
        }

        Ok(MessageHeader {
            magic,
            command,
            payload_length,
            checksum,
        })
    }

    /// Verify that the checksum matches the given payload.
    pub fn verify_checksum(&self, payload: &[u8]) -> bool {
        let hash = sha256_d(payload);
        self.checksum == hash[..4]
    }
}
```

```rust
use crate::decode::Reader;
use crate::error::SpvResult;
use tw_utxo::encode::stream::Stream;
use tw_utxo::encode::Encodable;

/// Bitcoin P2P version message.
/// Sent as the first message after TCP connection.
/// Matches breadwallet-core BRPeer.c version message construction.
#[derive(Debug, Clone)]
pub struct VersionMessage {
    pub version: u32,
    pub services: u64,
    pub timestamp: i64,
    pub recv_services: u64,
    pub recv_addr: [u8; 16], // IPv6-mapped address
    pub recv_port: u16,
    pub from_services: u64,
    pub from_addr: [u8; 16],
    pub from_port: u16,
    pub nonce: u64,
    pub user_agent: String,
    pub start_height: u32,
    pub relay: bool,
}

impl VersionMessage {
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        stream.append(&self.version);
        stream.append(&self.services);
        stream.append(&self.timestamp);
        stream.append(&self.recv_services);
        stream.append_raw_slice(&self.recv_addr);
        stream.append(&self.recv_port.to_be()); // port is big-endian
        stream.append(&self.from_services);
        stream.append_raw_slice(&self.from_addr);
        stream.append(&self.from_port.to_be()); // port is big-endian
        stream.append(&self.nonce);

        // user agent as var_str
        let ua_bytes = self.user_agent.as_bytes();
        stream.append(&tw_utxo::encode::compact_integer::CompactInteger::from(ua_bytes.len()));
        stream.append_raw_slice(ua_bytes);

        stream.append(&self.start_height);
        stream.append(&(self.relay as u8));
        stream.out()
    }

    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let version = reader.read_u32_le()?;
        let services = reader.read_u64_le()?;
        let timestamp = reader.read_i64_le()?;
        let recv_services = reader.read_u64_le()?;
        let mut recv_addr = [0u8; 16];
        recv_addr.copy_from_slice(&reader.read_bytes(16)?);
        let recv_port = reader.read_u16_be()?; // port is network byte order (big-endian)
        let from_services = reader.read_u64_le()?;
        let mut from_addr = [0u8; 16];
        from_addr.copy_from_slice(&reader.read_bytes(16)?);
        let from_port = reader.read_u16_be()?; // port is network byte order (big-endian)
        let nonce = reader.read_u64_le()?;
        let ua_bytes = reader.read_var_bytes()?;
        let user_agent = String::from_utf8_lossy(&ua_bytes).to_string();
        let start_height = reader.read_u32_le()?;
        let relay = if reader.remaining() > 0 {
            reader.read_u8()? != 0
        } else {
            true // BIP37: default to true if not present
        };

        Ok(VersionMessage {
            version,
            services,
            timestamp,
            recv_services,
            recv_addr,
            recv_port,
            from_services,
            from_addr,
            from_port,
            nonce,
            user_agent,
            start_height,
            relay,
        })
    }
}
```

```rust
// rust/frameworks/tw_spv/src/messages/inv.rs
// SPDX-License-Identifier: Apache-2.0

use crate::decode::Reader;
use crate::error::{SpvError, SpvResult};
use tw_hash::H256;
use tw_utxo::encode::compact_integer::CompactInteger;
use tw_utxo::encode::stream::Stream;

/// Witness flag for inv_type (BIP144).
const WITNESS_FLAG: u32 = 0x40000000;

/// Inventory vector type. Matches breadwallet-core inv_type enum.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum InvType {
    Tx,
    Block,
    FilteredBlock,
    WitnessTx,
    WitnessBlock,
    FilteredWitnessBlock,
}

impl InvType {
    pub fn from_u32(v: u32) -> SpvResult<Self> {
        match v {
            1 => Ok(InvType::Tx),
            2 => Ok(InvType::Block),
            3 => Ok(InvType::FilteredBlock),
            v if v == 1 | WITNESS_FLAG => Ok(InvType::WitnessTx),
            v if v == 2 | WITNESS_FLAG => Ok(InvType::WitnessBlock),
            v if v == 3 | WITNESS_FLAG => Ok(InvType::FilteredWitnessBlock),
            _ => Err(SpvError::InvalidData(format!("unknown inv type: {}", v))),
        }
    }

    pub fn to_u32(self) -> u32 {
        match self {
            InvType::Tx => 1,
            InvType::Block => 2,
            InvType::FilteredBlock => 3,
            InvType::WitnessTx => 1 | WITNESS_FLAG,
            InvType::WitnessBlock => 2 | WITNESS_FLAG,
            InvType::FilteredWitnessBlock => 3 | WITNESS_FLAG,
        }
    }
}

/// A single inventory vector (type + hash).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct InvVector {
    pub inv_type: InvType,
    pub hash: H256,
}

/// Inv message: announces known data objects (blocks, transactions).
#[derive(Debug, Clone)]
pub struct InvMessage {
    pub inventory: Vec<InvVector>,
}

impl InvMessage {
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        stream.append(&CompactInteger::from(self.inventory.len()));
        for inv in &self.inventory {
            stream.append(&inv.inv_type.to_u32());
            stream.append(&inv.hash);
        }
        stream.out()
    }

    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let count = reader.read_compact_int()? as usize;
        let mut inventory = Vec::with_capacity(count);
        for _ in 0..count {
            let inv_type = InvType::from_u32(reader.read_u32_le()?)?;
            let hash = reader.read_h256()?;
            inventory.push(InvVector { inv_type, hash });
        }
        Ok(InvMessage { inventory })
    }
}
```

```rust
/// GetBlocks and GetHeaders share the same wire format:
/// version(4) + count(varint) + locator_hashes(count * 32) + hash_stop(32)
#[derive(Debug, Clone)]
pub struct BlockLocatorMessage {
    pub version: u32,
    pub locator_hashes: Vec<H256>,
    pub hash_stop: H256,
}

impl BlockLocatorMessage {
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        stream.append(&self.version);
        stream.append(&CompactInteger::from(self.locator_hashes.len()));
        for hash in &self.locator_hashes {
            stream.append(hash);
        }
        stream.append(&self.hash_stop);
        stream.out()
    }

    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let version = reader.read_u32_le()?;
        let count = reader.read_compact_int()? as usize;
        let mut locator_hashes = Vec::with_capacity(count);
        for _ in 0..count {
            locator_hashes.push(reader.read_h256()?);
        }
        let hash_stop = reader.read_h256()?;
        Ok(BlockLocatorMessage {
            version,
            locator_hashes,
            hash_stop,
        })
    }
}
```

```rust
/// Headers message: up to 2000 block headers.
#[derive(Debug, Clone)]
pub struct HeadersMessage {
    pub headers: Vec<BlockHeader>,
}

impl HeadersMessage {
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        stream.append(&CompactInteger::from(self.headers.len()));
        for header in &self.headers {
            stream.append(header);
            // Each header is followed by a varint tx_count (always 0 in headers msg)
            stream.append(&CompactInteger::from(0_usize));
        }
        stream.out()

        let mut reader = Reader::new(data);
        let count = reader.read_compact_int()? as usize;
        let mut headers = Vec::with_capacity(count);
        for _ in 0..count {
            let header = BlockHeader::decode(&mut reader)?;
            let _tx_count = reader.read_compact_int()?; // always 0
            headers.push(header);
        }
        Ok(HeadersMessage { headers })
    }
}
```

```rust
/// A network address entry in the addr message.
#[derive(Debug, Clone)]
pub struct NetworkAddress {
    pub timestamp: u32,
    pub services: u64,
    pub address: [u8; 16], // IPv6-mapped
    pub port: u16,
}

/// Addr message: list of known peer addresses.
#[derive(Debug, Clone)]
pub struct AddrMessage {
    pub addresses: Vec<NetworkAddress>,
}

impl AddrMessage {
    pub fn serialize(&self) -> Vec<u8> {
        let mut stream = Stream::new();
        stream.append(&CompactInteger::from(self.addresses.len()));
        for addr in &self.addresses {
            stream.append(&addr.timestamp);
            stream.append(&addr.services);
            stream.append_raw_slice(&addr.address);
            stream.append(&addr.port.to_be());
        }
        stream.out()
    }

    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let count = reader.read_compact_int()? as usize;
        let mut addresses = Vec::with_capacity(count);
        for _ in 0..count {
            let timestamp = reader.read_u32_le()?;
            let services = reader.read_u64_le()?;
            let mut address = [0u8; 16];
            address.copy_from_slice(&reader.read_bytes(16)?);
            let port = reader.read_u16_be()?; // port is network byte order
            addresses.push(NetworkAddress {
                timestamp,
                services,
                address,
                port,
            });
        }
        Ok(AddrMessage { addresses })
    }
}
```

```rust
/// BIP61 reject codes.
pub const REJECT_INVALID: u8 = 0x10;
pub const REJECT_SPENT: u8 = 0x12;
pub const REJECT_NONSTANDARD: u8 = 0x40;
pub const REJECT_DUST: u8 = 0x41;
pub const REJECT_LOWFEE: u8 = 0x42;

/// Reject message (BIP61).
#[derive(Debug, Clone)]
pub struct RejectMessage {
    pub message: String,
    pub code: u8,
    pub reason: String,
    /// Extra data (e.g. tx hash for tx rejects). May be empty.
    pub data: Vec<u8>,
}

impl RejectMessage {
    pub fn parse(data: &[u8]) -> SpvResult<Self> {
        let mut reader = Reader::new(data);
        let msg_bytes = reader.read_var_bytes()?;
        let message = String::from_utf8_lossy(&msg_bytes).to_string();
        let code = reader.read_u8()?;
        let reason_bytes = reader.read_var_bytes()?;
        let reason = String::from_utf8_lossy(&reason_bytes).to_string();
        let extra = if reader.remaining() > 0 {
            reader.read_bytes(reader.remaining())?
        } else {
            Vec::new()
        };
        Ok(RejectMessage {
            message,
            code,
            reason,
            data: extra,
        })
    }
}
```

```rust
/// Tx message: a raw Bitcoin transaction.
/// For Phase 1, we store raw bytes and compute txid.
/// Full deserialization is delegated to tw_utxo's Transaction type.
#[derive(Debug, Clone)]
pub struct TxMessage {

    pub raw: Vec<u8>,

        TxMessage { raw }
    }

    pub fn txid(&self) -> H256 {
        let hash = sha256_d(&self.raw);
        let mut arr = [0u8; 32];
        arr.copy_from_slice(&hash);
        H256::from(arr)
    }

    pub fn serialize(&self) -> Vec<u8> {
        self.raw.clone()
    }
}
```

```rust
// rust/frameworks/tw_spv/src/peer.rs
// SPDX-License-Identifier: Apache-2.0

use crate::error::{SpvError, SpvResult};
use crate::messages::header::MessageHeader;
use crate::messages::version::VersionMessage;
use std::net::SocketAddr;
use std::time::Duration;

/// Service flags (from breadwallet-core BRPeer.h).
pub const SERVICES_NODE_NETWORK: u64 = 0x01;
pub const SERVICES_NODE_BLOOM: u64 = 0x04;
pub const SERVICES_NODE_WITNESS: u64 = 0x08;
/// BIP157: compact block filters support. Reserved for future Phase 5+ (design spec §9-5).
pub const SERVICES_NODE_COMPACT_FILTERS: u64 = 0x40;

/// Peer connection timeout values.
/// Matches breadwallet-core CONNECT_TIMEOUT / HANDSHAKE_TIMEOUT.
pub const CONNECT_TIMEOUT: Duration = Duration::from_secs(3);
pub const HANDSHAKE_TIMEOUT: Duration = Duration::from_secs(5);
pub const PING_TIMEOUT: Duration = Duration::from_secs(10);
/// If no message received for this long, consider peer dead.
pub const IDLE_TIMEOUT: Duration = Duration::from_secs(120);

/// Peer connection status.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PeerStatus {
    Disconnected,
    Connecting,
    Connected,
    /// Peer is being disconnected due to timeout.
    /// The caller should close the TCP connection and clean up.
    TimedOut,
}

/// Information about a known peer (stored in peer cache).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PeerInfo {
    pub address: SocketAddr,
    pub services: u64,
    pub timestamp: u64,
}

impl PeerInfo {
    /// Whether this peer advertises NODE_BLOOM support.
    pub fn supports_bloom(&self) -> bool {
        self.services & SERVICES_NODE_BLOOM != 0
    }

    /// Whether this peer advertises NODE_WITNESS support.
    pub fn supports_witness(&self) -> bool {
        self.services & SERVICES_NODE_WITNESS != 0
    }
}

/// Configuration for creating a new peer connection.
#[derive(Debug, Clone)]
pub struct PeerConfig {
    pub address: SocketAddr,
    pub magic_number: u32,
    pub protocol_version: u32,
    pub min_protocol_version: u32,
    pub user_agent: String,
    pub start_height: u32,
    pub earliest_key_time: u32,
}

/// State of a single peer connection.
/// Manages handshake and message exchange.
///
/// This struct does NOT own a TCP connection directly.
/// It operates on raw byte buffers (serialize/parse),
/// leaving actual I/O to the caller (PeerManager + runtime).
#[derive(Debug)]
pub struct PeerState {
    pub config: PeerConfig,
    pub status: PeerStatus,
    pub remote_version: Option<u32>,
    pub remote_user_agent: Option<String>,
    pub remote_start_height: Option<u32>,
    pub remote_services: Option<u64>,
    pub fee_per_kb: u64,
    pub nonce: u64,
    pub needs_filter_update: bool,
    pub version_sent: bool,
    pub version_ack_received: bool,
    pub version_received: bool,
    pub ping_nonce: u64,
    pub ping_time: Duration,
    /// Timestamp of last received message (for idle timeout detection).
    pub last_message_time: std::time::Instant,
    /// Timestamp when connection or handshake started (for connect/handshake timeout).
    pub connect_start_time: std::time::Instant,
}

impl PeerState {
    pub fn new(config: PeerConfig) -> Self {
        // Generate a unique nonce for version message.
        // Nonce is used for self-connection detection (BIP: if we receive our
        // own nonce back in a version message, we connected to ourselves).
        // Must NOT be deterministic per-address, otherwise reconnecting to
        // the same peer yields the same nonce → self-detection fails.
        let nonce = {
            let mut buf = [0u8; 8];
            let now = std::time::SystemTime::now()
                .duration_since(std::time::UNIX_EPOCH)
                .unwrap_or_default()
                .as_nanos();
            // Mix address + timestamp + thread ID for uniqueness
            let seed = format!(
                "{}:{}:{}",
                config.address,
                now,
                std::thread::current().id().as_u64()
            );
            let hash = tw_hash::sha2::sha256(seed.as_bytes());
            buf.copy_from_slice(&hash[..8]);
            u64::from_le_bytes(buf)
        };

        PeerState {
            config,
            status: PeerStatus::Disconnected,
            remote_version: None,
            remote_user_agent: None,
            remote_start_height: None,
            remote_services: None,
            fee_per_kb: 0,
            nonce,
            needs_filter_update: false,
            version_sent: false,
            version_ack_received: false,
            version_received: false,
            ping_nonce: 0,
            ping_time: Duration::ZERO,
            last_message_time: std::time::Instant::now(),
            connect_start_time: std::time::Instant::now(),
        }
    }

    /// Record that a message was received (resets idle timer).
    pub fn on_message_received(&mut self) {
        self.last_message_time = std::time::Instant::now();
    }

    /// Check if any timeout has been exceeded. Returns the new status
    /// if a timeout occurred, or None if everything is within bounds.
    ///
    /// The caller should invoke this periodically (e.g., every second)
    /// and disconnect the peer if it returns `Some(PeerStatus::TimedOut)`.
    pub fn check_timeout(&mut self) -> Option<PeerStatus> {
        let now = std::time::Instant::now();
        match self.status {
            PeerStatus::Connecting => {
                if now.duration_since(self.connect_start_time) > CONNECT_TIMEOUT {
                    self.status = PeerStatus::TimedOut;
                    return Some(PeerStatus::TimedOut);
                }
            }
            PeerStatus::Connected => {
                // Check handshake timeout
                if !self.is_handshake_complete()
                    && now.duration_since(self.connect_start_time) > HANDSHAKE_TIMEOUT
                {
                    self.status = PeerStatus::TimedOut;
                    return Some(PeerStatus::TimedOut);
                }
                // Check idle timeout
                if now.duration_since(self.last_message_time) > IDLE_TIMEOUT {
                    self.status = PeerStatus::TimedOut;
                    return Some(PeerStatus::TimedOut);
                }
            }
            _ => {}
        }
        None
    }

    /// Build the version message to send as handshake initiation.
    pub fn build_version_message(&self) -> Vec<u8> {
        let now = std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .unwrap_or_default()
            .as_secs() as i64;

        let addr = self.config.address;
        let recv_addr = match addr {
            SocketAddr::V4(a) => {
                let octets = a.ip().octets();
                let mut mapped = [0u8; 16];
                mapped[10] = 0xff;
                mapped[11] = 0xff;
                mapped[12..16].copy_from_slice(&octets);
                mapped
            }
            SocketAddr::V6(a) => a.ip().octets(),
        };

        let msg = VersionMessage {
            version: self.config.protocol_version,
            services: 0, // SPV client provides no services
            timestamp: now,
            recv_services: SERVICES_NODE_NETWORK | SERVICES_NODE_BLOOM,
            recv_addr,
            recv_port: addr.port(),
            from_services: 0,
            from_addr: [0u8; 16],
            from_port: 0,
            nonce: self.nonce,
            user_agent: self.config.user_agent.clone(),
            start_height: self.config.start_height,
            relay: false, // BIP37: don't relay tx until filter is set
        };

        msg.serialize()
    }

    /// Process a received version message.
    pub fn handle_version(&mut self, msg: &VersionMessage) -> SpvResult<()> {
        if msg.version < self.config.min_protocol_version {
            return Err(SpvError::InvalidData(format!(
                "peer version {} below minimum {}",
                msg.version, self.config.min_protocol_version
            )));
        }
        self.remote_version = Some(msg.version);
        self.remote_user_agent = Some(msg.user_agent.clone());
        self.remote_start_height = Some(msg.start_height);
        self.remote_services = Some(msg.services);
        self.version_received = true;
        Ok(())
    }

    /// Handle verack received.
    pub fn handle_verack(&mut self) {
        self.version_ack_received = true;
        if self.version_received {
            self.status = PeerStatus::Connected;
        }
    }

    /// Whether the handshake is complete.
    pub fn is_handshake_complete(&self) -> bool {
        self.version_sent && self.version_received && self.version_ack_received
    }

    /// Whether this peer supports bloom filtering (based on received service bits).
    pub fn supports_bloom(&self) -> bool {
        self.remote_services
            .map(|s| s & SERVICES_NODE_BLOOM != 0)
            .unwrap_or(false)
    }

    /// Wrap a message payload with the 24-byte header.
    pub fn frame_message(&self, command: &str, payload: &[u8]) -> Vec<u8> {
        let header = MessageHeader::new(self.config.magic_number, command, payload);
        let mut result = header.serialize();
        result.extend_from_slice(payload);
        result
    }
}
```

```rust
// rust/frameworks/tw_spv/src/peer_manager.rs
// SPDX-License-Identifier: Apache-2.0

use crate::chain::SpvChain;
use crate::events::{SyncCapability, SyncEvent};
use crate::peer::{PeerInfo, PeerStatus, SERVICES_NODE_BLOOM, SERVICES_NODE_NETWORK};
use std::net::{SocketAddr, ToSocketAddrs};

/// Resolve DNS seeds to peer addresses.
/// Returns PeerInfo entries for all resolved addresses with default services.
///
/// This function blocks on DNS resolution. The caller (SyncManager/runtime)
/// should invoke it from a blocking-capable context (e.g., spawn_blocking).
pub fn resolve_dns_seeds(seeds: &[&str], default_port: u16) -> Vec<PeerInfo> {
    let now = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs();

    let mut peers = Vec::new();
    for seed in seeds {
        let addr_str = format!("{}:{}", seed, default_port);
        match addr_str.to_socket_addrs() {
            Ok(addrs) => {
                for addr in addrs {
                    peers.push(PeerInfo {
                        address: addr,
                        // Assume full node + bloom until handshake reveals otherwise
                        services: SERVICES_NODE_NETWORK | SERVICES_NODE_BLOOM,
                        timestamp: now,
                    });
                }
            }
            Err(_) => {
                // DNS resolution failed for this seed — skip silently.
                // This is normal: some seeds may be unreachable temporarily.
                continue;
            }
        }
    }
    peers
}

/// Maximum number of concurrent peer connections.
/// Matches breadwallet-core PEER_MAX_CONNECTIONS.
const PEER_MAX_CONNECTIONS: usize = 3;
/// After this many connection failures, notify the user.
const MAX_CONNECT_FAILURES: u32 = 20;
/// After this many misbehaving events, clear peer list and re-query DNS.
const MAX_MISBEHAVIN_COUNT: u32 = 10;

/// Tracks the state of the peer pool and orchestrates peer selection.
/// Does NOT own TCP connections — that is the SyncManager/runtime's job.
pub struct PeerPool {
    /// All known peers, sorted by timestamp (most recent first).
    known_peers: Vec<PeerInfo>,
    /// Currently connected peers (indices into known_peers or separate tracking).
    connected: Vec<ConnectedPeer>,
    /// The peer selected for block download.
    download_peer_idx: Option<usize>,
    /// Consecutive connection failure count.
    connect_failure_count: u32,
    /// Misbehaving peer count (reset after clearing peer list).
    misbehavin_count: u32,
    /// Maximum concurrent connections.
    max_connections: usize,
    /// Current sync capability based on connected peers.
    capability: SyncCapability,
}

/// A connected peer with its status.
#[derive(Debug, Clone)]
struct ConnectedPeer {
    info: PeerInfo,
    remote_start_height: u32,
    supports_bloom: bool,
    is_synced: bool,
}

impl PeerPool {
    pub fn new() -> Self {
        PeerPool {
            known_peers: Vec::new(),
            connected: Vec::new(),
            download_peer_idx: None,
            connect_failure_count: 0,
            misbehavin_count: 0,
            max_connections: PEER_MAX_CONNECTIONS,
            capability: SyncCapability::Unsupported,
        }
    }

    /// Load known peers from cache, sorted by timestamp descending.
    pub fn load_peers(&mut self, peers: Vec<PeerInfo>) {
        self.known_peers = peers;
        self.known_peers
            .sort_by(|a, b| b.timestamp.cmp(&a.timestamp));
    }

    /// Add DNS-discovered peers (merged with existing, deduplicated by address).
    pub fn add_discovered_peers(&mut self, peers: Vec<PeerInfo>) {
        for peer in peers {
            if !self.known_peers.iter().any(|p| p.address == peer.address) {
                self.known_peers.push(peer);
            }
        }
        self.known_peers
            .sort_by(|a, b| b.timestamp.cmp(&a.timestamp));
    }

    /// Select the next peers to connect to.
    /// Returns up to `max_connections - connected.len()` peer addresses.
    pub fn peers_to_connect(&self) -> Vec<PeerInfo> {
        let needed = self.max_connections.saturating_sub(self.connected.len());
        if needed == 0 {
            return Vec::new();
        }

        self.known_peers
            .iter()
            .filter(|p| !self.connected.iter().any(|c| c.info.address == p.address))
            .take(needed)
            .cloned()
            .collect()
    }

    /// Record a successful connection.
    pub fn on_peer_connected(
        &mut self,
        info: PeerInfo,
        remote_start_height: u32,
        supports_bloom: bool,
    ) -> Vec<SyncEvent> {
        let mut events = Vec::new();
        self.connect_failure_count = 0;

        self.connected.push(ConnectedPeer {
            info: info.clone(),
            remote_start_height,
            supports_bloom,
            is_synced: false,
        });

        events.push(SyncEvent::PeerConnected(info.address));

        // Update capability and download peer
        self.update_capability(&mut events);
        self.select_download_peer();

        events
    }

    /// Record a disconnection.
    pub fn on_peer_disconnected(&mut self, addr: &std::net::SocketAddr) -> Vec<SyncEvent> {
        let mut events = Vec::new();
        self.connected.retain(|c| &c.info.address != addr);

        // If download peer disconnected, reselect
        if self
            .download_peer_idx
            .map(|i| i >= self.connected.len())
            .unwrap_or(true)
        {
            self.download_peer_idx = None;
            self.select_download_peer();
        }

        events.push(SyncEvent::PeerDisconnected(*addr));
        self.update_capability(&mut events);
        events
    }

    /// Record a connection failure.
    pub fn on_connect_failure(&mut self) -> Vec<SyncEvent> {
        self.connect_failure_count += 1;
        if self.connect_failure_count >= MAX_CONNECT_FAILURES {
            vec![SyncEvent::SyncFailed(
                crate::events::SyncError::MaxConnectionFailures {
                    count: self.connect_failure_count,
                },
            )]
        } else {
            Vec::new()
        }
    }

    /// Record a peer misbehaving.
    /// After MAX_MISBEHAVIN_COUNT, clears the peer list.
    /// Returns true if the peer list was cleared (need DNS re-query).
    pub fn on_peer_misbehaving(&mut self, addr: &std::net::SocketAddr) -> bool {
        // Remove from known peers
        self.known_peers.retain(|p| &p.address != addr);
        // Disconnect
        self.connected.retain(|c| &c.info.address != addr);

        self.misbehavin_count += 1;
        if self.misbehavin_count >= MAX_MISBEHAVIN_COUNT {
            self.misbehavin_count = 0;
            self.known_peers.clear();
            true // signal to re-query DNS
        } else {
            false
        }
    }

    /// Get the current download peer.
    pub fn download_peer(&self) -> Option<&PeerInfo> {
        self.download_peer_idx
            .and_then(|i| self.connected.get(i))
            .map(|c| &c.info)
    }

    /// Current sync capability.
    pub fn capability(&self) -> SyncCapability {
        self.capability
    }

    /// Number of connected peers.
    pub fn connected_count(&self) -> usize {
        self.connected.len()
    }

    /// Estimated network height (max of connected peers).
    pub fn estimated_height(&self) -> u32 {
        self.connected
            .iter()
            .map(|c| c.remote_start_height)
            .max()
            .unwrap_or(0)
    }

    // --- Internal ---

    /// Select download peer: connected peer with highest start_height
    /// that supports bloom filtering (if chain supports it).
    fn select_download_peer(&mut self) {
        self.download_peer_idx = self
            .connected
            .iter()
            .enumerate()
            .filter(|(_, c)| c.supports_bloom)
            .max_by_key(|(_, c)| c.remote_start_height)
            .map(|(i, _)| i);

        // If no bloom peers, fall back to any peer for header-only sync
        if self.download_peer_idx.is_none() {
            self.download_peer_idx = self
                .connected
                .iter()
                .enumerate()
                .max_by_key(|(_, c)| c.remote_start_height)
                .map(|(i, _)| i);
        }
    }

    /// Update sync capability based on connected peers.
    fn update_capability(&mut self, events: &mut Vec<SyncEvent>) {
        let old = self.capability;
        let has_bloom_peer = self.connected.iter().any(|c| c.supports_bloom);

        self.capability = if has_bloom_peer {
            SyncCapability::FullBip37
        } else if !self.connected.is_empty() {
            SyncCapability::HeaderOnly
        } else {
            SyncCapability::Unsupported
        };

        if self.capability != old {
            events.push(SyncEvent::CapabilityChanged(self.capability));
        }
    }
}
```

```rust
// rust/frameworks/tw_spv/src/sync_manager.rs
// SPDX-License-Identifier: Apache-2.0

use crate::chain::{BlockHeader, Checkpoint, SpvChain};
use crate::events::{SyncCapability, SyncEvent, SyncError};
use tw_hash::H256;
use std::collections::HashMap;

/// Filter strategy abstraction for future BIP157/158 support (design spec §9-5).
///
/// Phase 1 implements only `Bip37FilterStrategy`. When adding Neutrino support
/// in Phase 5+, implement this trait for compact block filters and plug it into
/// SyncState without modifying the sync state machine itself.
pub trait FilterStrategy: Send + Sync {
    fn filter_type(&self) -> SyncCapability;
    fn build_filter_message(&self, addresses: &[&str]) -> Vec<u8>;
    fn process_filtered_response(&self, data: &[u8]) -> Vec<H256>;
}

/// Sync state machine phases.
/// Implements breadwallet-core's modified sync protocol (BRPeer.c lines 60-86).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SyncPhase {
    /// Not started or stopped.
    Idle,
    /// Sending getheaders, receiving headers.
    /// Continue until a header within 1 week of earliest_key_time.
    HeaderSync,
    /// Sending getblocks/getdata, receiving merkleblock+tx.
    FilteredBlockSync,
    /// Sync complete, monitoring for new blocks.
    Monitoring,
}

/// Manages sync state and block chain state.
pub struct SyncState {
    phase: SyncPhase,
    earliest_key_time: u32,
    sync_start_height: u32,
    /// Validated block headers indexed by hash.
    headers: HashMap<H256, StoredHeader>,
    /// Reverse index: height → hash for O(1) lookup.
    /// Used by block_locators() which calls hash_at_height() repeatedly.
    height_index: HashMap<u32, H256>,
    /// Last (best) block header.
    last_header: Option<StoredHeader>,
    /// Checkpoints indexed by hash.
    checkpoints: HashMap<H256, Checkpoint>,
    /// Checkpoint height → hash for fast lookup.
    checkpoint_heights: HashMap<u32, H256>,
    /// Last header height.
    last_height: u32,
}

#[derive(Debug, Clone)]
struct StoredHeader {
    header: BlockHeader,
    height: u32,
    hash: H256,
}

impl SyncState {
    pub fn new<C: SpvChain>(chain: &C, earliest_key_time: u32) -> Self {
        let mut checkpoints = HashMap::new();
        let mut checkpoint_heights = HashMap::new();
        for cp in chain.checkpoints() {
            checkpoints.insert(cp.hash, *cp);
            checkpoint_heights.insert(cp.height, cp.hash);
        }

        SyncState {
            phase: SyncPhase::Idle,
            earliest_key_time,
            sync_start_height: 0,
            headers: HashMap::new(),
            height_index: HashMap::new(),
            last_header: None,
            checkpoints,
            checkpoint_heights,
            last_height: 0,
        }
    }

    pub fn phase(&self) -> SyncPhase {
        self.phase
    }

    pub fn last_height(&self) -> u32 {
        self.last_height
    }

    /// Start syncing.
    pub fn start_sync(&mut self) -> Vec<SyncEvent> {
        self.phase = SyncPhase::HeaderSync;
        self.sync_start_height = self.last_height;
        vec![SyncEvent::SyncStarted {
            start_height: self.sync_start_height,
        }]
    }

    /// Build block locator hashes for getheaders/getblocks.
    ///
    /// Algorithm from breadwallet-core BRPeerManager.c `_BRPeerManagerBlockLocators`:
    /// Append 10 most recent block hashes descending, then continue doubling
    /// the step back, finishing with the genesis block hash.
    ///
    /// Pattern: top, -1, -2, -3, ..., -9, -11, -15, -23, -39, -71, -135, ..., 0
    pub fn block_locators(&self) -> Vec<H256> {
        let mut locators = Vec::new();
        let mut height = self.last_height as i64;
        let mut step: i64 = 1;
        let mut count = 0;

        // Walk backwards from last block
        while height > 0 {
            if let Some(hash) = self.hash_at_height(height as u32) {
                locators.push(hash);
            }
            count += 1;
            if count >= 10 {
                step *= 2;
            }
            height -= step;
        }

        // Always include genesis (height 0)
        if let Some(hash) = self.hash_at_height(0) {
            if locators.last() != Some(&hash) {
                locators.push(hash);
            }
        }

        locators
    }

    /// Process received headers.
    /// Returns events and whether more headers should be requested.
    ///
    /// Each header's `prev_block` must chain to the previous header's hash.
    /// Headers that fail validation are rejected, and the peer should be
    /// marked as misbehaving by the caller.
    pub fn process_headers(
        &mut self,
        headers: &[BlockHeader],
        target_height: u32,
    ) -> Result<(Vec<SyncEvent>, bool), SyncError> {
        let mut events = Vec::new();

        for header in headers {
            let hash = header.block_hash();
            let height = self.last_height + 1;

            // --- CRITICAL: Verify prev_block chain continuity ---
            // Without this check, an attacker could inject disconnected headers.
            if let Some(ref last) = self.last_header {
                if header.prev_block != last.hash {
                    return Err(SyncError::InvalidHeaderChain {
                        height,
                        expected_prev: last.hash,
                        got_prev: header.prev_block,
                    });
                }
            } else if height > 0 {
                // If we have no last_header but height > 0, check against checkpoints
                if let Some(expected_hash) = self.hash_at_height(height - 1) {
                    if header.prev_block != expected_hash {
                        return Err(SyncError::InvalidHeaderChain {
                            height,
                            expected_prev: expected_hash,
                            got_prev: header.prev_block,
                        });
                    }
                }
            }

            // Verify header is not already known (duplicate detection)
            if self.headers.contains_key(&hash) {
                continue; // skip duplicate, not an error
            }

            let stored = StoredHeader {
                header: header.clone(),
                height,
                hash,
            };

            self.headers.insert(hash, stored.clone());
            self.height_index.insert(height, hash);
            self.last_header = Some(stored);
            self.last_height = height;
        }

        events.push(SyncEvent::HeadersProgress {
            current_height: self.last_height,
            target_height,
        });

        // Check if we should transition to filtered block sync.
        // breadwallet-core: transition when header timestamp is within 1 week of earliestKeyTime.
        let one_week = 7 * 24 * 60 * 60;
        let should_continue_headers = if let Some(last) = &self.last_header {
            last.header.timestamp + one_week < self.earliest_key_time
        } else {
            false
        };

        if !should_continue_headers && self.phase == SyncPhase::HeaderSync && !headers.is_empty() {
            self.phase = SyncPhase::FilteredBlockSync;
        }

        // Request more if we got max batch (2000 headers)
        let need_more = headers.len() >= 2000 && should_continue_headers;

        Ok((events, need_more))
    }

    /// Record a filtered block being applied.
    pub fn on_filtered_block_applied(
        &mut self,
        height: u32,
        matched_tx_count: usize,
        target_height: u32,
    ) -> Vec<SyncEvent> {
        let mut events = vec![SyncEvent::FilteredBlockApplied {
            height,
            matched_tx_count,
        }];

        if height >= target_height {
            self.phase = SyncPhase::Monitoring;
            events.push(SyncEvent::SyncCompleted { height });
        }

        events
    }

    /// Stop sync.
    pub fn stop_sync(&mut self) {
        self.phase = SyncPhase::Idle;
        self.sync_start_height = 0;
    }

    /// Compute sync progress (0.0 to 1.0).
    pub fn sync_progress(&self, target_height: u32) -> f64 {
        if target_height <= self.sync_start_height {
            return 1.0;
        }
        let total = (target_height - self.sync_start_height) as f64;
        let done = (self.last_height.saturating_sub(self.sync_start_height)) as f64;
        (done / total).min(1.0)
    }

    // --- Internal ---

    fn hash_at_height(&self, height: u32) -> Option<H256> {
        // O(1) lookup via height indexes (previously O(n) full scan)
        self.checkpoint_heights
            .get(&height)
            .or_else(|| self.height_index.get(&height))
            .copied()
    }
}
```

### Changes From Original Plan (Review Feedback Applied)

| # | Issue | Resolution |
|---|-------|------------|
| 1 | `process_headers()` accepted disconnected headers | Added `prev_block` chain continuity check with `InvalidHeaderChain` error |
| 2 | Genesis-only checkpoint (impractical for mobile) | Expanded to 42 mainnet + 5 testnet checkpoints at 20,160-block intervals |
| 3 | `hash_at_height()` was O(n) scan | Added `height_index: HashMap<u32, H256>` for O(1) lookup |
| 4 | Peer nonce was deterministic (same on reconnect) | Mixed timestamp + thread ID into nonce seed for uniqueness |
| 5 | Port encoding used confusing `swap_bytes()` | Added `read_u16_be()` to Reader, used explicitly for port fields |
| 6 | `verify_header_chain()` only checked timestamp | Added basic difficulty guard (reject >4x drop) + PoW verification |
| 7 | Missing protocol messages | Added `notfound`, `sendheaders` (BIP130), `tx` messages |
| 8 | No peer timeout handling | Added `TimedOut` status + `check_timeout()` with connect/handshake/idle timeouts |
| 9 | No DNS seed resolution | Added `resolve_dns_seeds()` helper in peer_manager |
| 10 | `BloomFilter::serialize()` relied on implicit Vec encoding | Explicit `CompactInteger + raw bytes` to guarantee BIP37 wire format |
| 11 | No BIP157/158 migration path in design | Added Section 9-5 with reserved `SyncCapability::CompactFilters` + `FilterStrategy` trait |
| 12 | Persistence had no atomic batch writes | Added `save_headers_batch()` + `save_sync_progress()` to Persistence trait |
