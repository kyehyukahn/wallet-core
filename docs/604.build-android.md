# 604. Android / Kotlin 빌드

wallet-core를 Android 앱과 Kotlin Multiplatform에서 사용하기 위한 빌드 가이드.

## 사전 조건

- [600. 빌드 사전 준비](600-build-prerequisites.md) 완료
- Android SDK, NDK 설치
- Java JDK (Android Gradle 빌드에 필요)

## Android 의존성 설치

```bash
tools/install-android-dependencies
```

설치되는 것:
- **CMake 3.18.1** (Android NDK용)
- **NDK 23.1.7779620**
- **System Image** android-30 (에뮬레이터 테스트용)
- **Dokka** (Kotlin 문서 생성 도구)

### Kotlin/KMP 빌드용 추가 의존성

```bash
tools/install-kotlin-dependencies
```

설치되는 것:
- **CMake 3.22.1**
- **NDK 25.2.9519653**

> Kotlin/KMP 빌드는 더 최신 NDK를 사용한다.

## 빌드 흐름

```
bootstrap.sh android
    ↓
tools/generate-files android    ← Android JNI 바인딩 생성
    ↓
tools/kotlin-build              ← Kotlin/KMP 라이브러리 빌드
    또는
tools/android-build             ← Android AAR 릴리즈 빌드
```

## Step 1: 코드 생성

```bash
tools/generate-files android
```

Android 타겟 시 추가 수행:
1. **Rust Android 크로스 컴파일** — 4개 아키텍처
   - `aarch64-linux-android` (arm64-v8a)
   - `armv7-linux-androideabi` (armeabi-v7a)
   - `x86_64-linux-android` (x86_64)
   - `i686-linux-android` (x86)
2. **Java Protobuf 코드 생성** — `protoc --java_out`
3. **JNI C 바인딩 생성** — codegen

## Step 2: Kotlin/KMP 빌드

```bash
tools/kotlin-build
```

내부적으로:
```bash
cd kotlin
./gradlew :wallet-core-kotlin:generateProtos
./gradlew :wallet-core-kotlin:assemble
```

## Step 3: 테스트

### Kotlin JVM 테스트 (에뮬레이터 불필요)

```bash
tools/kotlin-test

# 내부적으로:
# cd kotlin && ./gradlew :wallet-core-kotlin:jvmTest
```

### Android Instrumented 테스트 (에뮬레이터/디바이스 필요)

```bash
cd android && ./gradlew connectedAndroidTest
```

## Android AAR 릴리즈 빌드

```bash
tools/android-build
```

빌드 결과: `build/wallet-core.aar`

### 산출물 크기 참고

본 포크 기준 release 빌드 측정값 (Apple Silicon Mac, NDK 25/27/28, cmake 3.18.1):

| 산출물 | 항목 | 크기 |
|---|---|---|
| `wallet-core.aar` (zip) | 전체 | ~29 MB |
| 내부 `.so` (압축 해제) | jni/arm64-v8a/libTrustWalletCore.so | ~17.4 MB |
| | jni/armeabi-v7a/libTrustWalletCore.so | ~12.4 MB |
| | jni/x86_64/libTrustWalletCore.so | ~18.8 MB |
| | jni/x86/libTrustWalletCore.so | ~20.1 MB |
| | classes.jar (Kotlin/Java 바인딩) | ~86 KB |

`.so`는 release 정적 strip 후 크기로, iOS xcframework(~264 MB)에 비해 훨씬 작다.
AAR 자체는 GitHub의 파일당 100 MB 한도 이내라 직접 저장도 가능하지만,
iOS 산출물과 배포 채널을 일관되게 두기 위해 **GitHub Releases** 방식을 권장한다.

## CMake 빌드 설정 (Android)

CMakeLists.txt에서 `-DANDROID=ON` 시:
- **공유 라이브러리** (`.so`)로 빌드됨 (standalone의 정적 `.a`와 다름)
- JNI 바인딩 소스 포함 (`jni/cpp/`, `jni/android/`)
- 아키텍처별 Rust 라이브러리 자동 선택:

| ABI | Rust 타겟 |
|-----|----------|
| arm64-v8a | aarch64-linux-android |
| armeabi-v7a | armv7-linux-androideabi |
| x86_64 | x86_64-linux-android |
| x86 | i686-linux-android |

## Kotlin Multiplatform (KMP)

KMP 빌드는 `-DTW_COMPILE_JAVA=ON -DTW_COMPILE_KOTLIN=ON` 플래그를 사용한다. JNI 바인딩이 Kotlin 전용으로 변경됨:
- `jni/kotlin/` (Kotlin JNI)
- `kotlin/wallet-core-kotlin/src/commonAndroidJvmMain/cpp/generated/` (생성된 C 바인딩)

## 생성되는 파일 구조

```
jni/
├── cpp/               ← 공통 JNI C++ 래퍼
├── android/           ← Android JNI C 바인딩 (편집 금지)
├── kotlin/            ← Kotlin JNI C 바인딩 (편집 금지)
└── proto/             ← Java protobuf 생성 파일 (편집 금지)

kotlin/
├── wallet-core-kotlin/
│   ├── src/
│   │   ├── commonMain/generated/     ← 생성된 Kotlin 코드 (편집 금지)
│   │   └── commonAndroidJvmMain/cpp/ ← 생성된 C 바인딩
│   └── build.gradle.kts
└── build.gradle.kts

android/
├── app/
│   └── src/androidTest/  ← Instrumented 테스트
└── wallet-core/
    └── build/outputs/aar/ ← AAR 출력
```

## 앱에서 사용하기

### Gradle (GitHub Packages)

```groovy
// build.gradle
repositories {
    maven {
        url = uri("https://maven.pkg.github.com/trustwallet/wallet-core")
        credentials {
            username = "GitHub 사용자명"
            password = "GitHub Personal Access Token"
        }
    }
}

dependencies {
    implementation "com.trustwallet:wallet-core:$latestVersion"
}
```

### 로컬 AAR 사용

```groovy
dependencies {
    implementation files('path/to/wallet-core.aar')
}
```

## 주의사항

1. **BOOST_ROOT**: macOS에서 빌드 시 `export BOOST_ROOT=$(brew --prefix boost)` 필요
2. **NDK 버전 차이**: Android 빌드(`23.1.7779620`)와 Kotlin 빌드(`25.2.9519653`)가 다른 NDK를 사용
3. **Generated 파일 편집 금지**: `jni/android/`, `jni/kotlin/`, `kotlin/.../generated/` 하위는 자동 생성
