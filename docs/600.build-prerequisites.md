# 600. 빌드 사전 준비 (Prerequisites)

wallet-core를 빌드하기 위한 시스템 요구사항과 의존성 설치 가이드.

## 지원 플랫폼

| 호스트 OS | 네이티브 C++ | Rust | iOS | Android | WASM | Docker |
|-----------|:---:|:---:|:---:|:---:|:---:|:---:|
| macOS (Apple Silicon / Intel) | O | O | O | O | O | O |
| Ubuntu 22.04+ | O | O | X | O | O | O |

## 의존성 버전 (dependencies-version 기준)

| 라이브러리 | 버전 |
|-----------|------|
| GoogleTest | 1.16.0 |
| Check | 0.15.2 |
| nlohmann/json | 3.11.3 |
| Protobuf | 3.20.3 |
| Swift Protobuf | 1.18.0 |
| Rust toolchain | nightly-2025-12-11 |
| CMake | >= 3.18 |
| Emscripten (WASM) | 4.0.22 |

## macOS 의존성 설치

`tools/install-sys-dependencies-mac` 스크립트가 자동으로 설치하지만, 수동으로 하려면:

```bash
# Homebrew 패키지
brew install boost ninja xcodegen xcbeautify cmake

# Rustup (이미 설치되어 있으면 skip)
brew install rustup
rustup-init -y --default-toolchain none --no-update-default-toolchain

# BOOST_ROOT 환경변수 (zsh 기준)
echo 'export BOOST_ROOT=$(brew --prefix boost)' >> ~/.zprofile
source ~/.zprofile
```

## Linux (Ubuntu 22.04) 의존성 설치

Docker 환경 또는 직접 설치:

```bash
apt-get install -y \
    build-essential libtool autoconf pkg-config \
    ninja-build ruby-full \
    clang-14 llvm-14 libc++-dev libc++abi-dev \
    cmake libboost-all-dev ccache \
    wget curl git unzip xz-utils
```

> **주의**: CMakeLists.txt에서 clang 컴파일러를 강제한다. GCC로는 빌드 불가.

```bash
# clang-14를 기본 clang으로 심볼릭 링크
ln -s /usr/bin/clang-14 /usr/bin/clang
ln -s /usr/bin/clang++-14 /usr/bin/clang++
```

## Rust 툴체인 설치

`tools/install-rust-dependencies` 스크립트 사용:

```bash
tools/install-rust-dependencies dev   # dev 옵션: clippy, rustfmt, cargo-llvm-cov 포함
```

이 스크립트가 설치하는 것:

| 항목 | 세부 |
|------|------|
| 기본 툴체인 | nightly-2025-12-11 |
| Android 타겟 | aarch64-linux-android, armv7-linux-androideabi, x86_64-linux-android, i686-linux-android |
| iOS 타겟 | x86_64-apple-ios, aarch64-apple-ios-sim, aarch64-apple-ios |
| macOS 타겟 | aarch64-apple-darwin, x86_64-apple-darwin |
| WASM 타겟 | wasm32-unknown-emscripten |
| 도구 | cbindgen (C FFI 헤더 생성) |
| dev 전용 | llvm-tools-preview, clippy, rustfmt, cargo-llvm-cov |

## C++ 라이브러리 설치

`tools/install-dependencies` 스크립트가 다음을 빌드/설치한다 (`build/local/` 하위):

1. **GoogleTest** — C++ 단위 테스트 프레임워크
2. **Check** — TrezorCrypto 테스트용 C 테스트 프레임워크
3. **Protobuf 3.20.3** — 트랜잭션 직렬화
4. **protoc-gen-c-typedef / protoc-gen-swift-typealias** — 커스텀 protobuf 플러그인 (`protobuf-plugin/`)
5. **protoc-gen-swift** — Swift protobuf 코드 생성 (macOS만)

설치 경로: `build/local/{bin,lib,include}/`

## 원스텝 부트스트랩

모든 의존성을 한 번에 설치하려면:

```bash
# 기본 (native C++ 빌드 준비)
./bootstrap.sh

# 특정 타겟 포함
./bootstrap.sh android          # Android 의존성 추가
./bootstrap.sh wasm             # WASM/Emscripten 추가
./bootstrap.sh ios              # iOS (macOS에서만)
./bootstrap.sh all              # 전체
```

bootstrap.sh 수행 순서:
1. 시스템 의존성 설치 (brew / apt)
2. C++ 라이브러리 빌드 (`tools/install-dependencies`)
3. Rust 툴체인 설치 (`tools/install-rust-dependencies dev`)
4. (옵션) WASM / Android 의존성
5. 코드 생성 (`tools/generate-files`)

## 디렉토리 구조 (빌드 관련)

```
wallet-core/
├── build/
│   ├── local/           ← C++ 의존성 설치 위치 (PREFIX)
│   │   ├── bin/         ← protoc, protoc-gen-* 등
│   │   ├── lib/         ← libprotobuf, libgtest 등
│   │   └── include/     ← 헤더 파일들
│   └── (cmake build dir) ← cmake 빌드 출력
├── rust/target/         ← Rust 빌드 출력
│   ├── release/         ← native libwallet_core_rs.a
│   ├── wasm32-unknown-emscripten/release/
│   ├── aarch64-linux-android/release/
│   └── ...
├── emsdk/               ← Emscripten SDK (WASM 빌드 시)
└── tools/               ← 모든 빌드/테스트 스크립트
```
