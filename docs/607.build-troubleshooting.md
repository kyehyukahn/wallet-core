# 607. 빌드 트러블슈팅

wallet-core 빌드 시 자주 발생하는 문제와 해결 방법.

## 컴파일러 관련

### "You should use clang compiler" 에러

```
CMake Error: You should use clang compiler
```

**원인**: CMakeLists.txt에서 Clang을 강제. GCC로는 빌드 불가.

**해결**:
```bash
cmake -H. -Bbuild -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++
```

macOS에서는 기본 `clang`이 Apple Clang이므로 보통 문제없음. Linux에서는:
```bash
# clang-14 설치 후
export CC=clang-14
export CXX=clang++-14
# 또는 심볼릭 링크 생성
ln -s /usr/bin/clang-14 /usr/bin/clang
ln -s /usr/bin/clang++-14 /usr/bin/clang++
```

## Boost 관련

### Boost를 찾을 수 없음

```
Could not find a package configuration file provided by "Boost"
```

**macOS 해결**:
```bash
export BOOST_ROOT=$(brew --prefix boost)
# 영구 설정
echo 'export BOOST_ROOT=$(brew --prefix boost)' >> ~/.zprofile
```

**Linux 해결**:
```bash
apt-get install libboost-all-dev
```

## Protobuf 관련

### protoc not found

```
protoc: command not found
```

**원인**: `tools/install-dependencies`가 아직 실행되지 않았거나 실패.

**해결**:
```bash
tools/install-dependencies
# protoc 위치 확인
ls build/local/bin/protoc
```

### protoc 버전 불일치

생성된 .pb.h 파일과 링크되는 libprotobuf 버전이 다르면 빌드 에러 발생.

**해결**: protoc와 libprotobuf 모두 동일 버전(3.20.3)이어야 함.
```bash
build/local/bin/protoc --version
# libprotoc 3.20.3 이어야 함
```

시스템에 다른 버전의 protoc가 있으면 PATH에서 `build/local/bin`이 먼저 오도록 설정:
```bash
export PATH="$PWD/build/local/bin:$PATH"
```

## Rust 관련

```

```

**해결**:

### cbindgen not found

```
cbindgen: command not found
```

**해결**:
```bash

```

### Rust 크로스 컴파일 타겟 미설치

```
error: target 'aarch64-apple-ios' not found
```

**해결**:
```bash
rustup target add aarch64-apple-ios
# 또는 전체 타겟 설치
tools/install-rust-dependencies
```

### cargo build 메모리 부족 / 멈춤

Rust 릴리즈 빌드는 메모리를 많이 사용한다 (특히 `-Z build-std`).

**해결**:
- 병렬 빌드 줄이기: `CARGO_BUILD_JOBS=4 cargo build --release`
- swap 확보
- Docker에서 메모리 제한 증가

### libwallet_core_rs.a 없음

```
cannot find -lwallet_core_rs
```

**원인**: Rust 빌드가 실행되지 않았거나 실패.

**해결**:
```bash
# Rust 라이브러리 수동 빌드
cd rust && cargo build --release --lib && cd ..
cp rust/target/release/libwallet_core_rs.a build/local/lib/

# 또는 generate-files가 자동으로 수행
tools/generate-files native
```

## 코드 생성 관련


### protoc-gen-swift 미설치

```
protoc-gen-swift: program not found
```

**원인**: `tools/install-dependencies`에서 Swift Protobuf 빌드가 실패했거나 macOS가 아닌 환경.

**해결** (macOS):

```bash
# 없으면 install-dependencies 재실행
tools/install-dependencies
```

### `-Wimplicit-int-float-conversion` → archive 실패 (최신 clang)

```
error: implicit conversion from 'int64_t' (aka 'long long') to 'double'
       may lose precision [-Werror,-Wimplicit-int-float-conversion]
```

**원인**: Xcode 16+의 clang이 기존 코드(`Bitcoin/InputSelector.cpp:182`)에서 발생하는
경고를 새로 잡아낸다. `WalletCoreCommon` 타겟의
`CLANG_WARN_SUSPICIOUS_IMPLICIT_CONVERSION: YES_ERROR` 설정이 이를 에러로 승격시킨다.

**해결**: `swift/common-xcframework.yml`의 `WalletCoreCommon` 타겟 `OTHER_CFLAGS`에
`-Wno-implicit-int-float-conversion` 추가 (본 포크에 이미 반영됨):

```yaml
OTHER_CFLAGS: $(inherited) -Wno-comma -Wno-implicit-int-float-conversion
```

### "iOS 26.5 is not installed" — generic/platform=iOS destination 실패

```
xcodebuild: error: Unable to find a destination matching the provided destination specifier:
   { platform:iOS, name:Any iOS Device }
   { platform:iOS, ... error:iOS 26.5 is not installed.
     Please download and install the platform from Xcode > Settings > Components. }
```

**원인**: 최신 Xcode는 iOS SDK와 별도로 **iOS platform 지원 컴포넌트**(device 빌드용)를
별도로 다운로드해야 한다. `-showsdks`에 `iphoneos26.5`가 표시돼도 platform이 없으면
device 슬라이스 archive가 실패한다 (macOS / Mac Catalyst 슬라이스는 영향 없음).

**해결**: Xcode → Settings → **Components** → 해당 iOS 버전의 platform 다운로드.
설치 후 `xcodebuild -showdestinations`로 "Any iOS Device" 항목에 `error:` 표시가 사라졌는지 확인.

### WalletCoreRs.xcframework가 없다고 `tools/ios-build` 실패

```
error: There is no XCFramework found at '.../swift/WalletCoreRs.xcframework'.
```

**원인**: Rust xcframework는 `tools/rust-bindgen ios`(또는 `tools/generate-files ios`)가
생성한다. 이 단계를 건너뛰면 `tools/ios-build`의 archive가 실패한다.

**해결**: 빌드 순서를 지킬 것 — `tools/generate-files ios` → `tools/ios-build`.

### `[CXX1300] CMake '3.18.1' was not found` — gradle 빌드 실패

```
Execution failed for task ':wallet-core:configureCMakeRelease[arm64-v8a]'.
> [CXX1300] CMake '3.18.1' was not found in SDK, PATH, or by cmake.dir property.
```

**원인**: `android/wallet-core/build.gradle`이 `externalNativeBuild.cmake.version "3.18.1"`로
고정돼 있는데, Android SDK에 해당 버전이 없을 때 발생. 시스템 cmake(예: 3.22, 3.31)는
gradle이 인식하지 않는다.

**해결**:
```bash
$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager "cmake;3.18.1"
```

### Emscripten Boost 헤더 없음

`tools/install-wasm-dependencies`가 자동으로 설치하지만, 수동으로:
```bash
cd emsdk

unzip boost-headers-1.83.0.zip -d upstream/emscripten/system/include
```

### `tw_spv` / `tokio` / `mio` 때문에 wasm 빌드 실패

```
error[E0583]: file not found for module `selector`
  --> .../mio-1.0.2/src/sys/unix/mod.rs:52:5
error: could not compile `mio` (lib) due to 26 previous errors
```

**원인**: `features/bitcoin_spv` 브랜치가 추가한 `tw_spv` 크레이트는 tokio async 런타임
(`tw_spv/src/runtime/tokio.rs`)을 사용한다. tokio는 `mio`에 의존하는데, `mio`의 unix 백엔드는
`wasm32-unknown-emscripten` 타겟용 시스템 모듈(`sys/unix/...`)을 가지고 있지 않다 →
컴파일 단계에서 26개 unresolved import 에러.

**현 상태 (2026-06-12 해결)**: `tools/rust-bindgen`의 wasm 분기가
`--no-default-features --features any-coin,bitcoin,ethereum,evm,keypair,solana,ton,utils`
(= default에서 `spv`만 제외)로 빌드하도록 변경 — wasm 타겟에서
`libwallet_core_rs.a` (14 MB) 생성 그린 확인. FFI는 `#[cfg(feature = "spv")]`로
gate되어 있고 codegen도 SPV 헤더 2개(`TWBitcoinSpvSync.h`,
`TWBitcoinWalletManager.h`)를 `SKIP_HEADERS`로 제외하므로 심볼/글루 정합이
유지된다.

**런타임 교체(위 복구안 2)를 선택하지 않은 이유**: 브라우저는 raw TCP를 열 수
없어 Bitcoin P2P(8333) 접속이 어떤 런타임으로도 불가능하다. wasm-호환 async
런타임으로 컴파일을 통과시켜도 "연결이 영원히 안 되는" 코드가 바이너리 크기만
차지한다. wasm 프로파일은 서명 전용(전 체인 서명/주소/HDWallet 포함), 체인
데이터는 HTTP 인덱서/RPC — 정책 상세는 [605.build-wasm.md](605.build-wasm.md)
상단 박스 참조.

**장래 웹 SPV가 필요하면**: `tw_spv/src/runtime.rs`의 `SpvRuntime` trait에
WebSocket + TCP 변환 프록시 기반 구현체를 추가 (별도 프로젝트 규모).

## 일반 팁

### 클린 빌드

문제가 지속되면 클린 빌드:
```bash
# C++ 빌드 캐시 삭제
rm -rf build/
# (주의: build/local/도 삭제되므로 install-dependencies 다시 필요)

# Rust 빌드 캐시 삭제
cd rust && cargo clean && cd ..

# WASM 빌드 캐시 삭제
rm -rf wasm-build/

# 전체 재빌드
./bootstrap.sh
```

### 부분 클린 (의존성 유지)

```bash
# C++ 빌드만 클린 (의존성은 유지)
rm -rf build/CMakeCache.txt build/CMakeFiles build/tests build/libTrustWalletCore.a

# cmake 재설정
cmake -H. -Bbuild -DCMAKE_BUILD_TYPE=Debug -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++
```

### 빌드가 멈추는 경우

- **메모리 부족**: 병렬 빌드 수 줄이기 (`-j4` 대신 `-j2`)
- **Rust 빌드 멈춤**: `cargo build`에 `--jobs 4` 옵션 추가
- **프로세스 확인**: `top` 또는 `htop`으로 메모리/CPU 사용량 확인
- **타임아웃**: 일부 자동화 도구(Claude Code 등)에서 타임아웃 발생 가능. 단계별로 나누어 실행 권장

## 빌드 순서 요약 (Quick Reference)

```bash
# 최초 설정 (1회)
./bootstrap.sh

# 일상 개발 루프
tools/generate-files native                    # proto/registry 변경 시
cmake -H. -Bbuild -DCMAKE_BUILD_TYPE=Debug -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++
make -Cbuild -j12 tests
./build/tests/tests --gtest_filter="*MyChain*"

# 또는 한 번에
tools/build-and-test
```
